# 一级建造师真题在线练习

多科目多年份题库中心，内置 21 套真题/冲刺卷共 1940 题（经济 640 · 管理 500 · 法规 800），
支持导入自己的题库，并带有**答题进度管理**、**多端进度同步**和**错题考点分析**。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主程序。本地用 `python3 -m http.server` 起服务后打开即可 |
| `bank_*.js` / `questions.js` | 题库数据，通过 `window.QUIZ_BANKS` 注册 |
| `build-standalone.js` | 把上面这些 `.js` 内联进 `index.html`，产出单文件 `exam-app.html` |
| `exam-app.html` | 自包含单文件版，供 Claude Artifact 发布使用（Artifact 只托管单个文件） |

改完 `index.html` 或题库后，记得跑一次 `node build-standalone.js` 重新打包。

## 答题进度管理

进度按**题号**存储在浏览器 `localStorage`，每道题都带最后作答时间戳：

```
yjjc_prog2:<题库id>   {v:2, u:整卷最后更新, pos:最近看到的题号,
                       q:{ 题号: [已选项, 标志位, 时间戳] }}
```

标志位：`bit0` 已确认作答 · `bit1` 已看答案 · `bit2` 本题正确。未作答的题不落盘，
所以存储量随做题量增长，而不是随题库大小增长。旧版按位置存储的 `yjjc_prog:<题库id>`
会在首次打开时自动迁移，不会丢进度。

**哪些做过、哪些没做**，在三个地方一眼可见：

- 首页「学习总览」：已做 / 未做 / 正确率 / 错题数，加一条分段进度条
  （绿＝答对、黄＝部分得分、红＝答错、灰＝只看了答案、空白＝未做）。
- 每张题库卡片：已做 N · 未做 M · 正确率 · 错题数 · 最后作答时间，同款分段条。
- 做题页答题卡：按题号显示每道题的对错状态；筛选条可只看「错题」或「未答」。

另有三个快捷入口：**继续上次**（回到最后看的那道题）、**做未做的题**
（优先接着已开始的卷子往下做）、**重做全部错题**。

## 多端同步

同一份试题在手机、平板、电脑上打开时，用「🔄 进度同步」把进度带过去。三种方式：

1. **同步码** —— 生成一串文本，复制到另一台设备粘贴导入。全部 1940 题做满也只有约 6 KB。
2. **同步链接** —— 同步码拼在页面地址后面（`#yj=...`），另一台设备直接打开就会提示合并。
3. **备份文件** —— 导出 JSON，除进度外还含自行导入的题库和每日学习记录，适合换设备整体恢复。

合并规则是**按每道题的最后作答时间取新**：A 设备做了 1–30 题、B 设备做了 31–60 题，
合并后两边都是 1–60 题；同一道题两边都做过，则以作答时间较晚的那次为准。
所以来回同步不会丢数据，也不需要区分"主设备"。另有「覆盖本机」模式，用于明确以某台设备为准。

同步码里也会带上本机存有、但当前设备没装的题库的进度（比如对方自行导入的卷子），
导入同名题库后这些记录会自动显现。

> 数据只在浏览器本地和你自己复制的这串文本里流转，不经过任何服务器。

## 错题分析与考点巩固

「📊 学习分析」分三个页签：

- **总览** —— 整体进度、各科目掌握情况、单选/多选正确率对比、近 14 天做题量。
  多选正确率明显低于单选时会给出提示。
- **错题本** —— 跨全部题库汇总错题，可按科目、题型、考点筛选；每道题显示你的选择、
  正确答案、所属考点，可展开解析、单题重做，或一键「重做这些错题」。
- **考点分析** —— 按考点统计做过 / 错题 / 错误率 / 未做，错误率高的排在前面，
  并给出「薄弱考点 TOP5」。每个考点都可以一键生成**强化练习**：先做该考点的错题，
  再做没做过的题。

考点取自本仓库四色笔记的章节划分（`notes/eco-war`、`notes/cmd-core`、`notes/law-fort`），
按题干和解析里的关键词自动归类，命中越具体的词权重越高。法规另加了一个「税费与保险法律制度」
分组，用来收纳真题里确实出现、但不属于笔记任一章节的税收与保险题。当前 1940 道题中约 96%
能归到具体考点，其余显示为「未归类」，同样可以统计和练习。

**强化练习组里的作答会写回原题库**，所以在错题本里把一道题重做对了，它就从错题本消失、
在原卷进度里也变成答对，不会出现两套互相打架的记录。

## 发布为 Claude Artifact

```bash
node build-standalone.js     # 生成 exam-app.html
```

发布时建议声明 `capabilities: { downloads: true }`。进度、同步码、错题分析都在浏览器本地
运行，不依赖任何能力；只有「导出备份文件」需要它——artifact 沙箱会拦掉页面自己发起的下载，
声明后改走 `claude.use("downloads")` 由查看者确认保存。未声明时该按钮会退回普通 Blob 下载
（在 artifact 里可能无声失败），同步码和同步链接不受影响。
