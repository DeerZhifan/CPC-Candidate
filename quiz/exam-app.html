导入格式说明

导入其他年份或科目（管理 / 法规 / 实务）的真题，推荐用 文本智能解析，也可用 JSON。

方式一 · 文本智能解析（最简单）

在"📝 文本智能解析"页签，填科目/年份，把整份试卷文字粘贴进去即可。识别规则：

  • 题号：以 1.、2、 等数字开头。
  • 选项：以 A. B、 C． D 开头。
  • 答案：写 答案：C 或 答案：ABC（多选）。
  • 解析：写 解析：……，可多行，直到下一题。
  • 也支持题目在前、末尾统一列答案表（如 1.C 2.A 3.D）。
  • 单选/多选自动判断（按答案个数，或章节标题"多项选择题"）。

方式二 · JSON

  • subject：科目，写 经济 / 管理 / 法规 / 实务，或写完整名称（含关键字即可自动识别）。
  • year：年份，如 "2020"。
  • title：标题（实务可写专业，如"建筑工程管理与实务"）。
  • questions：题目数组。每题字段：
    • type：single(单选) 或 multiple(多选)，也可写"单选/多选"；不写则按答案个数自动判断。
    • stem：题干。
    • options：选项，可写 [{"key":"A","text":"..."}]，也可只写字符串数组 ["...","..."]（自动编号 A/B/C）。
    • answer：正确答案，如 "B"、"ABC"、["A","C"] 均可。
    • analysis：解析（可选）。

也可导入多个题库：JSON 顶层写成题库数组 [ {...}, {...} ]。
