项目全等（固定）节拍加快的成倍节拍非节奏

2. 全等节拍流水工期
流水施工工期 =（施工段数 + 施工过程数 − 1）× 流水步距 + 技术间歇之和 − 提前插入之和
3. 加快的成倍节拍流水计算［2024单选］ 表4-6
流水步距 = min（各施工过程流水节拍）＝流水节拍的最大公约数；
专业工作队数目 = 流水节拍 ÷ 流水步距（各过程之和）；
流水施工工期 =（施工段数 + 专业工作队数 − 1）× 流水步距 + 技术间歇 − 提前插入
4. 非节奏流水［2017、2025单选］ 表4-7：流水步距用"累加数列错位相减取大差法"（①累加数列 ②错位相减 ③取大差）。
流水施工工期 = ∑流水步距 + 最后一个施工过程各段流水节拍之和 + 技术间歇 − 提前插入
【2025年真题】某分部工程有3个施工过程，划分为4个施工段组织非节奏流水施工，节拍见下表，则流水施工工期是（ ）d。（Ⅰ:3,5,3,4 / Ⅱ:4,3,4,3 / Ⅲ:5,4,5,4）A.21 B.22 C.25 D.26
答案 D。累加数列错位相减：K(Ⅰ,Ⅱ)=max{3,4,4,4,−14}=4；K(Ⅱ,Ⅲ)=max{4,2,2,0,−18}=4；工期=(4+4)+(5+4+5+4)=26d。

4.3.2 时间参数计算方法★★★★★2016~2025单选/多选（核心计算点）▶
参数含义 表4-11：ES最早开始、EF最早完成、LS最迟开始、LF最迟完成、TF总时差、FF自由时差。
1. 双代号工作计算法（口诀"最早看紧前多个取最大，最迟看紧后多个取最小"）
ES：起点节点=0，其他工作 = max{紧前工作 EF}；EF = ES + 持续时间
计算工期 = max{终点节点为箭头节点的工作 EF}
LF：终点节点 = 计划工期，其他工作 = min{紧后工作 LS}；LS = LF − 持续时间
总时差 TF = LS − ES = LF − EF（唯一线路=线路总时差；多线路=各线路总时差最小值）
自由时差 FF = min{紧后工作 ES} − 本工作 EF（无紧后=计划工期 − EF）
⚠ TF=0 时 FF 必为 0；同一工作 FF ≤ TF。总时差=计算工期 − 经过该工作各线路持续时间之和的最大值。
2. 双代号节点计算法［2019单选，2018、2025多选］ 表4-15
节点最早时间 ETj = max{ETi + Di-j}；节点最迟时间 LTi = min{LTj − Di-j}
ESi-j=ETi；EFi-j=ETi+Di-j；LFi-j=LTj；LSi-j=LTj−Di-j
TFi-j=LTj−ETi−Di-j；FFi-j=ETj−ETi−Di-j
3. 单代号网络计划（表4-16~4-18）：相邻两项工作时间间隔 LAG = 紧后工作 ES − 本工作 EF；
终点工作 TFn=Tp−EFn，其他 TFi=min{TFj+LAGi,j}；
终点工作 FFn=Tp−EFn，其他 FFi=min{LAGi,j}；
LF=EF+TF，LS=ES+TF
4. 双代号时标网络计划［多年单选/多选］：波形线水平投影长度 = 时间间隔；ES=箭线左端节点时标值；EF=右端节点（无波形线）或实线部分右端点（有波形线）；总时差用波形线累加法/取最小法；凡自始至终不出现波形线的线路即为关键线路。
5. 单代号搭接网络计划［2020、2023单选］ 表4-20~4-21：搭接关系 FTS/FTF/STS/STF；LAG = min{各时距对应差值}（口诀"时距为STS/STF：开始加时距，遇完成减持续；时距为FTF/FTS：完成加时距，遇完成减持续"）。
【2020年真题·六时标注】某双代号网络计划关键线路 A→D→E→I，计算工期15d，工作 G 总时差=（15−7）−（2+4）=2d；工作 F 自由时差=(2+4+6)−(2+4+4)=2d。
掌握"六时标注法"（ES/LS/TF ‖ EF/LF/FF）可一图求全部参数。
4.3.3 关键工作及关键线路确定方法★★★★★2016~2025单选/多选▶
1. 双代号网络计划 表4-22
  • 关键工作：总时差最小的工作（计划工期=计算工期时，总时差为零的工作）
  • 关键线路：关键工作首尾相连、持续时间总和最大的通路；关键线路上可能有虚工作存在
  • 标号法：起点标号0，bj=max{bi+Di-j}，从终点逆箭线按源节点确定关键线路
2. 关键节点与关键工作、关键线路的关系 图4-21
  • 关键工作两端节点必为关键节点，但两端为关键节点的工作不一定是关键工作
  • 关键节点必然处在关键线路上，但由关键节点组成的线路不一定是关键线路
  • 以关键节点为完成节点的工作，其总时差和自由时差必然相等
3. 单代号网络计划［2024单选，2022、2023多选］ 表4-23：总时差最小的工作为关键工作；相邻工作时间间隔全部为零的线路为关键线路。
⚠ 常见错误说法（表4-24）：持续时间最长的工作是关键工作（×）；关键线路只有一条（×）；关键线路一经确定不可转移（×）；无虚箭线的线路是关键线路（×）；由关键节点连成的线路是关键线路（×）。

4.4.2 实际进度与计划进度比较方法★★★★2016·2024·2025单选，2020·2023多选▶

2. S曲线比较法 表4-26：（口诀"左侧及上方，超前与超额；右侧及下方，拖后与拖欠"）实际进展点落在计划S曲线左侧=超前，右侧=拖后；上方=任务量超额，下方=任务量拖欠。
3. 前锋线比较法［2016、2024单选，2020、2023多选］ 表4-27
位置点实际进度对后续/总工期影响
落在检查日左侧拖后（检查时刻−位置点时刻）超过自由时差就影响后续、超过总时差就影响总工期，超几天影响几天
与检查日重合一致不影响
落在检查日右侧超前需结合其他工作分析
【2024年真题·前锋线】第6周末检查：工作C（关键工作）拖后2周→影响工期2周；工作D总时差1周，拖后1周→不影响总工期；工作E（非关键）提前1周→不影响。
前锋线判断口诀：拖后量与"自由时差/总时差"比大小定影响。
