8.1.2 各方主体绿色施工职责★★★2024·2025单选，2026修改▶
1. 绿色施工相关理念、原则和方法［2025单选］［2026修改］ 图8-2
理念/方法要点
可持续发展理念主要考量：资源的永续利用、环境容量的承载能力；三项基本原则：公平性、持续性、共同性
清洁生产理念"三清一控"——清洁的原料与能源、清洁的生产过程、清洁的产品，贯穿清洁生产全过程控制
环境伦理要求整体性、不损害性、补偿性要求；特点：倡导生态效益优先、低碳化转型、树立全寿命期系统观
循环经济"3R"原则减量化、再利用、再循环
生命周期评估（LCA）方法材料产品层面指导选择；建造层面描述环境足迹；行业管理层面利于政策制定和规划
2. 各方主体绿色施工职责［2024单选］ 表8-2：施工单位是绿色施工的实施主体，应建立以项目经理为第一责任人的绿色施工管理体系；实行总承包管理的由总承包单位对绿色施工负总责。
3. 绿色施工措施 图8-3：管理措施 + 技术措施（节材、节水、节能、节地 + 环境保护 + 采用"四新"）。
4. 环境保护［2024、2025单选］ 表8-3：噪声与振动控制——昼间场界≤70dB(A)、夜间≤55dB(A)，夜间噪声最大声级超限幅度不得高于15dB(A)；垃圾回收利用——再利用和回收率达30%，拆除产生的废弃物＞40%，碎石土石类＞50%，有毒有害废弃物分类率100%。
8.2 施工现场环境管理▶
8.2.1 施工现场文明施工要求★★★2024单选/多选，2026修改▶
1. 文明施工的管理理念［2024单选］［2026修改］：企业社会责任理念、精益管理理念、"8S"管理理念——整理(Seiri)、整顿(Seiton)、清扫(Seiso)、清洁(Seiketsu)、素养(Shitsuke)称"5S"；增加安全(Safety)为"6S"；再增加节约(Save)、学习(Study)为"8S"。
2. 文明施工管理工作要求［2024多选］ 图8-4：建立健全文明施工管理体系；抓好员工教育培训（对管理人员和施工人员的教育是重点）；制定安全文明施工管理规划（应在工程开工前编制）；落实安全文明施工费依规专款专用（建设单位及时足额支付、施工单位设专用账户建台账）。
3. 施工现场文明施工具体要求 表8-4：安全警示标志牌；现场围挡（封闭围挡高度≥1.8m）；五牌一图（工程概况、管理人员名单及监督电话、安全生产、文明施工、消防保卫五牌 + 施工现场总平面图）；企业标志、场容场貌、材料堆放、现场防火、垃圾清运。
8.2.2 施工现场环境保护措施★★★2024·2025单选▶
1. 控制项内容［2024单选］ 图8-5：绿色施工策划文件应包含环境保护内容并建立管理制度；施工现场在醒目位置设置环境保护标识；对古迹文物树木及生态环境采取有效保护措施，制定地下文物保护应急预案。
2. 一般项内容［2025单选］ 表8-5
项目关键指标
扬尘控制洒水清扫制度；遇六级及以上大风停止土方作业；高空垃圾清运采用封闭式管道或垂直运输机械
建筑垃圾处置装配式建筑垃圾排放量不大于200t/万m²，非装配式不大于300t/万m²；回收利用率达30%，材料包装物回收利用率达100%
污水排放工程污水和试验室养护用水处理合格后排入市政污水管道，检测频率不应少于1次/月
噪声控制施工场界声强限值昼间≤70dB(A)、夜间≤55dB(A)
3. 优选项内容：装配式建筑垃圾排放量宜不大于140t/万m²、非装配式宜不大于210t/万m²；回收利用率宜达50%；宜设扬尘自动监测仪（TSP、PM₁₀）和噪声监测设施。
