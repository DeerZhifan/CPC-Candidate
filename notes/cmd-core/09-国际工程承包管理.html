9.1 国际工程承包市场开拓▶
9.1.1 国际工程承包相关政策★★★2025单选▶
1. 促进对外承包工程高质量发展基本原则［2025单选］：坚持企业主体、质量优先、互利共赢、规范有序。
2. 对外承包市场开拓和健康发展政策要求 图9-1：加快建筑业企业"走出去"、加快形成对外承包工程发展新优势、共建"一带一路"推动国际工程承包转型升级。
3. 企业境外投资管理［2025单选］：投资主体依法享有境外投资自主权，自主决策、自担风险；实行核准管理的范围是投资主体直接或通过其控制的境外企业开展的敏感类项目，核准机关是国家发展和改革委员会。
4. 对外承包工程项目备案和立项管理 表9-1：一般项目在商务主管部门备案（投标或议标前）；特定项目经商务部会同国务院有关部门批准立项；承包项目后续报告——投标/议标结果公布、合同签订、开工、完工后30个工作日内填报。
5. 企业境外经营合规管理指引 表9-2：合规管理原则（独立性、适用性、全面性原则）；合规审计——企业合规管理职能应与内部审计职能分离。
9.1.2 国际工程承包市场进入★★★2024多选▶
1. 国际工程招标投标 表9-3：政府出资项目多采用公开招标；私人筹资项目招标限制较少或允许多种方式并存；使用某一特定国家政府贷款项目，一般在援助国国籍公司中公开招标，也可两国政府协商确定实施单位。
2. 外籍劳务要求［2024多选］：不同国家外籍劳务输入规定影响我国企业投标策划和项目组织实施；一般需申请劳务输入配额、办理居留签证和工作许可，并常对技术水平、工作经验、受教育程度、从业工种和就业期限加以限制。
3. 税收政策 表9-4：标准——属地主义、属人主义、属地兼属人原则；税种——流转税（营业税、增值税、消费税、进口关税、许可证税、印花税）、收益税（公司所得税、个人所得税）、财产税、杂项税。
9.2 国际工程承包风险及应对策略▶
9.2.1 国际工程承包风险★★★风险类型▶
图9-2：政治风险（所在国政局稳定性、政党轮替、政府干预、制裁禁运）、经济风险（通货膨胀、汇率波动、利率变化）、市场风险（市场疲软、成本攀升、低价竞标）、自然风险、社会风险、合同风险（文本不完整、条款不清晰、显失公平、索赔困难）、资金风险、技术风险、法律风险、合规风险。
9.2.2 国际工程承包风险应对策略★★★2024单选，2025多选▶
图9-3
  • 加强市场调研，建立安全风险评估机制
  • 综合运用多种策略，用金融工具（远期合约、期权合约、货币期货/外汇期货、货币互换/货币掉期）化解融资汇率风险
  • 精准有序开拓市场，避免低价恶性竞争
  • 建立风险处置机制、强化安全意识、开展属地化经营、遵守当地法律制度严格合规、践行ESG（环境、社会和治理）、发挥保险保障功能
9.3 国际工程投标与合同管理▶
9.3.1 国际工程投标策略★★★报价策略▶
1. 不同项目投标报价水平的选择 表9-5：可偏低报价（施工条件好、工程量大、投标对手多竞争激烈、急于打入某市场、设备无工地转移时）；可偏高报价（施工条件差、技术密集有专长、总价低的小工程、投标对手少、工期紧、支付条件不理想）。
2. 不平衡报价策略 图9-4：预计工程量增加的项目单价适当高报，减少的适当报低；前期工程偏高报价，后期工程偏低报价；不计入标价或仅有内容项无数量的（计日工、备品备件）适当偏高报价；大概率实施的暂定项单价适当高报，大概率不实施的适当低报。
9.3.2 FIDIC施工合同和EPC合同管理★★★2024·2025单选，2025多选（高频）▶
1. FIDIC施工合同文件组成及优先解释顺序［2025单选］：①合同协议书 → ②中标函 → ③投标函 → ④专用条件A部分（合同数据）→ ⑤专用条件B部分（特别规定）→ ⑥通用条件 → ⑦规范要求 → ⑧图纸 → ⑨资料表 → ⑩联营体承诺书 → ⑪其他文件。
2. 通用条件专用词语定义［2024单选］ 表9-6
词语定义
费用（成本）承包商合理开支（含税费管理费），但不包括利润
费用加利润合同数据中规定的费用加适当比例利润（未规定则按5%）
基准日期提交投标书截止日期前28d的日期
3. 施工进度管理［2026修改］ 表9-8：工程师应在开工日期前至少14d通知；开工日期在承包商收到中标函后42d内；承包商收到开工通知后28d内提交初步进度计划；暂停工程持续超过84d，承包商可通知要求复工，工程师28d内未同意则可视为变更甩项。
4. 工程量估价和支付［2024、2025单选］ 表9-9：工程师现场测量应提前7d通知承包商；期中付款——工程师收到报表后28d内签发付款证书，业主收到报表后56d内付款；最终付款证书业主56d内付款；延误按3%年利率计融资费用。
5. 工程接收 表9-11：承包商竣工前不少于14d发出申请签发接收证书通知，工程师收到申请后28d内签发或拒绝并说明理由。
6. FIDIC EPC（银皮书）合同管理［2025多选］ 表9-12
  • 合同文件优先顺序：①合同协议书 →②专用条件 →③通用条件 →④业主要求 →⑤明细表 →⑥投标书 →⑦联合体保证 →⑧其他
  • 业主代表/承包商代表更换应不少于14d前通知；分包商应不少于28d前向业主通知；工期索赔只有3种情形（合同变更、合同条件规定的延长、业主或其他承包商造成的延误阻碍）
【2025年真题】根据FIDIC《施工合同条件》，合同组成文件包括：①图纸；②资料表；③规范要求。仅就上述合同文件而言，正确的优先解释顺序是（ ）。A.①—②—③ B.②—③—① C.③—①—② D.②—①—③
答案 C。规范要求＞图纸＞资料表。
