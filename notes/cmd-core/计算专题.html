1流水施工

用流水节拍与流水步距组织连续、均衡施工。三种基本方式：全等节拍、加快成倍节拍、非节奏流水。

全等（固定）节拍流水工期
T = (m + n − 1)·K + Σ间歇 − Σ提前
m施工段数 · n施工过程数 · K流水步距（=节拍）
各过程节拍全相等
加快成倍节拍流水
K = 各节拍最大公约数；n′ = Σ(ti/K)
n′专业工作队总数（>过程数）；T = (m + n′ − 1)·K + 间歇 − 提前
同过程节拍相等、不同过程成倍数关系
非节奏流水（累加错位相减取大差法）
T = ΣK + Σ末过程节拍 + Σ间歇 − Σ提前
流水步距 K：①各过程节拍累加成数列 ②相邻错位相减 ③取差中最大值
节拍不全相等（最常考）
⚠ 加快成倍节拍中"专业工作队数 n′ ≠ 施工过程数 n"，工期公式里用 n′。非节奏流水求步距别忘"取大差"，且末尾补一个 0 参与相减。
经典例题 1-A非节奏流水
某分部工程 3 个施工过程、4 个施工段组织非节奏流水，节拍（d）如下。求流水工期。
过程\段①②③④
Ⅰ3534
Ⅱ4343
Ⅲ5454
解：累加错位相减取大差 Ⅰ累加：3,8,11,15；Ⅱ累加：4,7,11,14；Ⅲ累加：5,9,14,18 K(Ⅰ,Ⅱ)=max(3,8−4,11−7,15−11,0−14)=max(3,4,4,4,−14)=4 K(Ⅱ,Ⅲ)=max(4,7−5,11−9,14−14,0−18)=max(4,2,2,0,−18)=4 T=ΣK+Ⅲ过程节拍和=(4+4)+(5+4+5+4)=8+18=26 d
答：流水施工工期 26 d。

2网络计划·时间参数计算

全书最核心计算点。掌握双代号"工作计算法"与"节点计算法"，再迁移到单代号。

双代号 · 工作计算法

最早时间（顺推，取大）
ES = max{紧前工作 EF}；EF = ES + D
起点工作 ES=0；D=持续时间
计算工期 = max{终点工作 EF}
最迟时间（逆推，取小）
LF = min{紧后工作 LS}；LS = LF − D
终点工作 LF = 计划工期
从终点倒推
总时差 TF
TF = LS − ES = LF − EF
不影响总工期的机动时间
TF=0（计划=计算工期时）即关键工作
自由时差 FF
FF = min{紧后工作 ES} − 本工作 EF
无紧后工作时 FF = 计划工期 − EF
不影响紧后工作最早开始的机动时间
💡 恒等关系：FF ≤ TF；TF=0 ⇒ FF=0。总时差还可用"计算工期 − 经过该工作各条线路持续时间之和的最大值"求得。

双代号 · 节点计算法

节点最早/最迟时间
ETj=max{ETi+Dij}；LTi=min{LTj−Dij}
起点 ET=0；终点 LT=计划工期
先求全部节点时间
由节点时间求工作参数
TFij=LTj−ETi−Dij；FFij=ETj−ETi−Dij
ES=ETi，EF=ETi+D，LF=LTj，LS=LTj−D
节点法算 TF/FF 更快

单代号网络计划

相邻工作时间间隔 LAG
LAGi,j = ESj − EFi
紧后工作最早开始 − 本工作最早完成
单代号关键线路判据：LAG 全为 0 的线路
时差（逆推）
TFi=min{TFj+LAGi,j}；FFi=min{LAGi,j}
终点工作 TF=FF=计划工期−EF
LS=ES+TF，LF=EF+TF
经典例题 2-A六时参数
某双代号网络：A(2)起点；B(3)紧前A；C(4)紧前A；D(2)紧前B、C；E(3)紧前D。求各工作时间参数、计算工期与关键线路。
解：顺推 ES/EF A:0~2；B:2~5；C:2~6；D:max(5,6)=6~8；E:8~11 ⇒ 计算工期 = 11 逆推 LF/LS（LF终=11） E:8~11；D:6~8；C:2~6；B:LF=6,LS=3；A:LF=min(3,2)=2,LS=0 总时差 TF=LS−ES A=0，B=3−2=1，C=0，D=0，E=0

3关键工作、关键线路与工期优化

关键工作＝总时差最小；关键线路＝关键工作首尾相连且持续时间之和最大。

标号法求关键线路
bj = max{bi + Dij}
起点 b=0，逐节点标号并记来源节点；从终点逆着来源回溯即关键线路
快速定关键线路与工期
工期优化（压缩关键工作）
优先压：直接费用率最小的关键工作
多条关键线路需同时压缩，取组合直接费用率之和最小者
费用优化：总成本=直接费+间接费最低
⚠ 常见错误说法：①"持续时间最长的工作是关键工作"（×，应看总时差）②"关键线路只有一条、不可转移"（×，压缩后可能转移）③"由关键节点连成的线路一定是关键线路"（×）。

4时标网络与搭接网络判读

时标网络"看图读参数"；搭接网络掌握四种时距关系。

双代号时标网络
波形线水平投影长度 = 相邻工作时间间隔
ES=箭线左端节点时标；EF=实线右端；自始至终无波形线的线路=关键线路
TF 用波形线累加法/取小法
搭接网络四种时距
FTS / FTF / STS / STF
F=完成、S=开始；如 STS=紧前开始到紧后开始的最小间隔
按时距推 ES/EF，间隔为 0 处判关键
💡 时标网络自由时差最直观：工作箭线末端波形线的水平投影长度就是该工作的自由时差；一条线路上波形线长度之和最小者更接近关键线路。

5挣值法（偏差分析）

用三个基本参数、四个评价指标，同时衡量成本与进度偏差。成本管理的核心计算。

三参数
BCWP·BCWS·ACWP
BCWP已完预算(挣值)=Σ已完量×预算单价；BCWS拟完预算=Σ计划量×预算单价；ACWP已完实际=Σ已完量×实际单价
"两已完、一拟完"
费用偏差 / 进度偏差
CV = BCWP − ACWP；SV = BCWP − BCWS
CV<0 超支、SV<0 拖后（>0 反之）
绝对偏差，仅同一项目分析
费用/进度绩效指数
CPI = BCWP/ACWP；SPI = BCWP/BCWS
<1 不利、>1 有利
相对偏差，可跨项目比较
⚠ 记忆钩子："偏差=相减、指数=相除；分子永远是 BCWP（挣值）；带 C 配 ACWP（成本），带 S 配 BCWS（进度）"。负值/小于1均为不利。
经典例题 5-A挣值四指标
某工程至第 4 月末：拟完工程预算费用 330 万、已完工程预算费用 350 万、已完工程实际费用 300 万。分析成本与进度状况。
解：BCWS=330，BCWP=350，ACWP=300 CV=350−300=+50 万（>0，成本节约） SV=350−330=+20 万（>0，进度提前） CPI=350/300=1.17（>1，省钱）；SPI=350/330=1.06（>1，超前）
答：成本节约、进度提前，项目状况良好（省钱又超前）。

6因素分析法（连环置换法）

成本分析基本方法，逐个分析各因素对成本的影响程度。

连环置换法则
以目标数为基础，按顺序逐个用实际数替换，替换后保留
排序：先实物量、后价值量；先绝对值、后相对值
某因素影响 = 该次替换结果 − 上次替换结果
⚠ 各因素替换顺序不能颠倒（顺序不同结果不同）；每算一个因素时，前面的因素已替换为实际值并保留，后面的因素仍为目标值。
经典例题 6-A连环置换
砖基础目标成本与实际对比：工程量 计划 500 m³、实际 510 m³；砖消耗 529、530 块/m³；单价 0.26、0.25 元/块。求各因素对成本的影响（顺序：工程量→消耗量→单价）。
解：目标 = 500×529×0.26 = 68 770 元 ① 替工程量：510×529×0.26 = 70 145.4 → 影响 = 70 145.4−68 770 = +1375.4 元 ② 替消耗量：510×530×0.26 = 70 278 → 影响 = 70 278−70 145.4 = +132.6 元 ③ 替单价：510×530×0.25 = 67 575 → 影响 = 67 575−70 278 = −2703 元 合计影响 = 1375.4+132.6−2703 = −1195 元（= 实际67 575 − 目标68 770）✓
答：工程量增加 +1375.4 元、消耗量增加 +132.6 元、单价下降 −2703 元，综合降本 1195 元。

7进度定额（综合时间定额·持续时间）

编制单位工程施工进度计划时的基础计算。

综合时间定额（合并工作）
H = Σ(QiHi) / ΣQi
Qi各分项工程量 · Hi各分项时间定额
两个分项合并为一项工作时
工作持续时间
D = P / (R · B)
P工作量(劳动量/台班量) · R每班人数或机械台班数 · B每天工作班数
最小工作面限 R 上限，最小劳动组合限 R 下限
经典例题 7-A综合时间定额
工作 A 由 B、C 两分项合并：B 时间定额 0.35 工日/m²、工程量 5000 m²；C 时间定额 0.52 工日/m²、工程量 3000 m²。求 A 的综合时间定额。
解： H = (0.35×5000 + 0.52×3000)/(5000+3000) = (1750+1560)/8000 = 3310/8000 = 0.41 工日/m²
答：综合时间定额 0.41 工日/m²。
