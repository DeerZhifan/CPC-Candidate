6.1 会计要素组成及计量▶
6.1.1 会计要素的组成★★★★★2018·2023·2024·2025单选 / 2018·2019·2021多选 / 2026修订▶

1. 静态会计要素（资产、负债、所有者权益）——反映企业某一时点财务状况

要素组成
资产·流动资产货币资金、交易性金融资产、衍生金融资产、应收票据、应收账款、应收款项融资、预付款项、其他应收款、存货、合同资产、持有待售资产、一年内到期的非流动资产、其他流动资产
资产·非流动资产债权投资、其他债权投资、长期应收款、长期股权投资、其他权益工具投资、其他非流动金融资产、投资性房地产、固定资产、在建工程、生产性生物资产、油气资产、使用权资产、无形资产、开发支出、商誉、长期待摊费用、递延所得税资产、其他非流动资产
负债·流动负债短期借款、交易性金融负债、衍生金融负债、应付票据、应付账款、预收款项、合同负债、应付职工薪酬、应交税费、其他应付款、持有待售负债、一年内到期的非流动负债、其他流动负债
负债·非流动负债长期借款、应付债券、租赁负债、长期应付款、预计负债、递延收益、递延所得税负债、其他非流动负债
所有者权益实收资本（或股本）、资本公积、盈余公积、未分配利润、其他权益工具、其他综合收益、专项储备
⚠ 判断口诀："应收为资、应付为债"——带"应收/预付"的科目属资产，带"应付/预收/应交"的属负债。选项常把"预收款项"混入资产、"预付款项"混入负债设坑。

2. 动态会计要素（收入、费用、利润）——反映企业某一时期经营成果

  • 收入：企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益的总流入；只有在经济利益很可能流入从而导致企业资产增加或者负债减少、且流入额能够可靠计量时才能予以确认
  • 费用：企业在日常活动中发生的、会导致所有者权益减少的、与向所有者分配利润无关的经济利益的总流出；只有在经济利益很可能流出从而导致企业资产减少或者负债增加、且流出额能够可靠计量时才能予以确认
  • 利润：企业在一定会计期间的经营成果；包括收入减去费用后的净额、直接计入当期利润的利得和损失等
⚠ 收入≠利得、费用≠损失：收入/费用限于日常活动；直接计入当期利润的利得和损失不属于收入/费用，而是计入利润。且收入须"与所有者投入资本无关"、费用须"与向所有者分配利润无关"——股东投资入账不是收入，分红不是费用。
6.1.2 会计要素计量属性★★★★2016·2020·2021·2022单选 / 2024多选 / 2026修订▶
计量属性资产负债
历史成本按照购置时支付的现金或者现金等价物的金额，或者按照购置资产时所付出的对价的公允价值计量按照因承担现时义务而实际收到的款项或资产的金额，或者承担现时义务的合同金额，或按日常活动中为偿还负债预期需要支付的现金或现金等价物的金额计量
重置成本（也称现行成本）按照现在购买相同或者相似资产所需支付的现金或者现金等价物的金额计量按现在偿付该项债务所需支付的现金或现金等价物的金额计量
可变现净值按照其现在正常对外销售所能收到现金或者现金等价物的金额，扣减该资产至完工时估计将要发生的成本、估计的销售费用以及相关税费后的金额计量—
现值按照预计从其持续使用和最终处置中所产生的未来净现金流入量的折现金额计量按照预计期限内需要偿还的未来净现金流出量的折现金额计量
公允价值按照市场参与者在计量日发生的有序交易中，出售资产所能收到或者转移负债所需支付的价格计量
⚠ 历史成本看"购置时"、重置成本看"现在购买"、可变现净值要"扣减后续成本+销售费用+税费"、现值必带"折现"二字、公允价值强调"有序交易"。已提折旧不影响历史成本原值。
【2022年真题】3年前购置价值30万元的设备，现以20万元卖出，需发生维修成本2万、销售费用1万、税金0.5万，可变现净值为（ ）万元？
答案 A：16.5。可变现净值 = 20 − 2 − 1 − 0.5 = 16.5 万元（与3年前的30万无关）。
【2020年真题】2年前以20万元购买的设备，累计已提折旧4万元，现在市场上购买同样设备需15万元，历史成本和重置成本分别为（ ）？
答案 A：20万元和15万元。历史成本=购置时支付额20万（不扣折旧）；重置成本=现在购买同样资产的支出15万。
6.2 财务会计工作基本内容▶
6.2.1 财务会计内涵★★★2024单选▶
  • 基本职能：核算 与 监督（两项）
  • 关键环节（四个）：
    • 会计确认——对发生的交易或事项，按一定标准辨析其能否确认为会计主体的一个或多个会计要素、何时输入会计信息系统以及如何进行会计报告的过程；标准是可定义性、可计量性、相关性和可靠性
    • 会计计量——对确认为会计要素的交易或事项按照计量属性确定其金额的过程
    • 记录——对经确认和计量的交易或事项及其金额，按一定规则和方法，通过分解、综合、汇总等手段记入有关账簿的过程
    • 报告——编制财务会计报告，为报告使用者提供有关会计信息的过程
⚠ "核算、监督"是职能；"确认、计量、记录、报告"是关键环节——两组概念选项常互混。
6.2.2 财务会计工作内容★★★2025单选▶
工作内容
会计核算工作(1)资产的增减和使用 (2)负债的增减 (3)净资产（所有者权益）的增减 (4)收入、支出、费用、成本的增减 (5)财务成果的计算和处理 (6)需要办理会计手续、进行会计核算的其他事项
会计监督工作真实性审查：检查各项经济业务事项是否真实以及会计核算是否与实际发生的经济业务一致。
合法性审查：检查各项经济业务是否符合国家有关法律法规，遵守财经纪律，执行国家各项方针政策；广义的合法性审查还包括各项经济业务是否符合企业会计准则、企业会计制度、企业财务会计制度等的规定。
合理性审查：检查各项财务收支是否符合客观规律及经营管理方面的要求，是否符合特定的财务收支计划
其他管理工作与资金相关：(1)账实核对 (2)进行税收筹划 (3)按时进行纳税申报 (4)提出资金利用计划建议 (5)协同编制收支计划 (6)进行企业非会计人员财税知识培训 (7)开展财务分析 (8)参与企业年度预算编制 (9)进行企业年终决算
⚠ 监督三审查对应关系：真实性=与实际业务一致；合法性=符合法律法规/财经纪律（广义含会计准则、会计制度）；合理性=符合客观规律与财务收支计划——题目常拿"符合收支计划"考合理性。
6.2.3 会计档案管理★★★▶
项目内容
归档范围(1)会计凭证：原始凭证、记账凭证。(2)会计账簿：总账、明细账、日记账、固定资产卡片及其他辅助性账簿。(3)财务会计报告：月度、季度、半年度、年度财务会计报告。(4)其他会计资料：银行存款余额调节表、银行对账单、纳税申报表、会计档案移交清册、会计档案保管清册、会计档案销毁清册、会计档案鉴定意见书及其他具有保存价值的会计资料
保管期限分为永久、定期两类；定期保管期限一般分为 10年和30年；保管期限从会计年度终了后的第一天算起
⚠ 定期保管期限是 10年和30年（不是5年/15年/25年）；起算点是会计年度终了后第一天，不是凭证形成之日。
6.3 会计假设与会计基础▶
6.3.1 会计假设★★★2024单选 / 2025多选 / 2026修订▶

四大会计假设（助记：主体经营，货币分期）：

假设要点
会计主体假设从空间上界定了会计工作的范围和立场
持续经营假设假定企业在可预见的未来持续经营下去
会计分期假设规定了会计对象的时间界限
货币计量假设以货币作为统一计量单位
⚠ 会计主体=空间范围，会计分期=时间界限——"空间/时间"互换是常见错项。
6.3.2 会计基础★★★2017单选▶
会计基础内容
收付实现制以款项是否在当期实际收到或付出为标准确认收支。某一会计期间内实际收到的收入和支付的费用，无论其是否应归属当期，均应作为当期的收入和费用处理；凡当期未曾收到的收入和未曾支付的费用，即使应归属当期，也不应作为当期的收入和费用处理
权责发生制凡当期实际发生并应归属当期的收入、支出和费用，无论其款项是否收到或付出，均应作为当期的收入和费用处理；凡不应属于当期的收入和费用，即使款项已经收到或支付，亦不应作为当期的收入、支出和费用处理
⚠ 收付实现制看"钱有没有收/付"；权责发生制看"权利义务是否在当期发生（应归属）"，与收付款时间无关。企业会计采用权责发生制。
【经典例题】建设单位2024年10月审核了竣工结算书，按合同应于2024年11月支付结算款项，施工企业实际于2025年1月收到，按现行《权责发生制》应将该款项计入（ ）的收入。
答案 B：2024年11月。权责发生制下按合同约定应收款的归属期（2024年11月）确认收入，与实际收款的2025年1月无关。
6.4 会计核算过程与会计等式▶
6.4.1 会计核算原则★★★2023·2024单选 / 2026修订▶
原则要点
重要性对影响财务报表使用者经济决策的重要信息单独、详细反映，对次要信息可简化处理；从定量和定性两个方面判别
谨慎性确认、计量和报告应保持应有的谨慎，不应高估资产或者收益、低估负债或者费用
实质重于形式按交易或事项的经济实质进行确认、计量和报告，不应仅以法律形式为依据；典型运用：融资租赁、售后回购、售后回租、合并报表的编制、关联方交易等
可比性会计信息应当具有可比性；同一企业不同时期发生的相同或者相似的交易或事项，应当采用一致的会计政策，不得随意变更
相关性会计信息应当与财务会计报告使用者的经济决策需要相关
明晰性会计信息应当清晰明了，便于财务会计报告使用者理解和使用
及时性对已经发生的交易或事项，应当及时进行会计确认、计量和报告，不得提前或者延后
客观性如实反映符合确认和计量要求的各项会计要素及其他相关信息，保证会计信息真实可靠、内容完整
⚠ 融资租赁、售后回购/回租、合并报表、关联方交易 → 实质重于形式；"不得高估资产、低估负债" → 谨慎性；"不得提前或延后" → 及时性；"会计政策不得随意变更" → 可比性。
6.4.2 会计核算的基本过程★★★▶

四步：①设置会计科目和账簿 → ②填制会计凭证 → ③登记账簿、对账和结账 → ④编制财务会计报告

会计信息形成路径
建科目、账簿先搭核算框架
填会计凭证原始凭证→记账凭证
登记、对账、结账形成账簿记录
编财务报告输出会计信息

会计凭证（分原始凭证、记账凭证）要点：

  • 凭证必须具备：名称、填制日期、填制单位名称或填制人姓名、经办人签名或盖章、接受凭证单位名称、经济业务内容、数量、单价和金额
  • 从外单位取得的原始凭证，必须盖有填制单位的公章；从个人取得的必须有填制人员的签名或盖章；对外开出的原始凭证必须加盖本单位公章
  • 凡填有大写和小写金额的原始凭证，大写与小写金额必须相符
  • 一式几联的原始凭证，应当注明各联的用途，只能以一联作为报销凭证
  • 原始凭证记载的各项内容均不得涂改；原始凭证有错误的，应当由出具单位重开或者更正，更正处应当加盖出具单位印章；原始凭证金额有错误的，应当由出具单位重开，不得在原始凭证上更正

会计记账方法：

  • 分单式记账法、复式记账法；复式记账法主要有借贷记账法、增减记账法和收付记账法
  • 企业应当采用借贷记账法记账
  • 对账要求：会计账簿记录与实物及款项的实有数额相符、会计账簿记录与会计凭证的有关内容相符、会计账簿之间相对应的记录相符、会计账簿记录与会计报表的有关内容相符（账实、账证、账账、账表相符）
⚠ 原始凭证内容错误→出具单位更正+盖章或重开；金额错误→只能重开，不得更正。两种处理方式是高频坑。
6.4.3 会计等式及其应用★★★2025单选 / 2021·2022多选▶
项目内容公式
静态会计等式反映企业某一时点财务状况资产 = 负债 + 所有者权益
动态会计等式反映企业某一时期经营成果收入 − 费用 = 利润
综合会计等式一定时期的经营活动成果将使企业财务状况发生改变资产 + 费用 = 负债 + 所有者权益 + 收入
⚠ 静态等式对应时点（资产负债表），动态等式对应时期（利润表）；综合等式左边是"资产+费用"、右边是"负债+所有者权益+收入"，各项归边勿记反。
6.5 会计监督▶
6.5.1 内部会计控制★★★2024多选▶

1. 内部会计控制管理制度（13项）：

  • 内部会计管理体系、会计人员岗位责任制度、账务处理程序制度、内部牵制制度、稽核制度、原始记录管理制度、定额管理制度、计量验收制度、财产清查制度、财务收支审批制度、成本核算制度、财务会计分析制度

2. 内部会计控制的方法：

  • 主要包括：不相容职务相互分离控制、授权批准控制、会计系统控制、预算控制、财产保全控制、风险控制、内部报告控制、电子信息技术控制等；不相容职务相互分离控制是内部控制的核心
  • 不相容职务主要包括：授权批准、业务经办、会计记录、财产保管、稽核检查等职务；出纳人员不得兼任稽核、会计档案保管和收入、支出、费用、债权债务账目的登记工作
⚠ 出纳"三不兼"：不得兼任稽核、会计档案保管、收入/支出/费用/债权债务账目登记。出纳做现金收付、网上转账、支票开具保管属本职工作，不违规。
【2024年真题】下列出纳人员工作安排中，违背企业内部控制"不相容职务相互分离"原则的有（ ）。A.负责现金收款 B.负责网上转账操作 C.负责会计档案管理 D.负责支票的开具和保管 E.负责稽核工作
答案 C、E。出纳不得兼任稽核（E）、会计档案保管（C）及收支费用债权债务账目登记；A、B、D均为出纳本职工作。
