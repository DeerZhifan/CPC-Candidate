建设工程经济 · 公式速查卡考前一页纸

全部核心公式一屏浓缩（三篇分色：■工程经济 ■工程财务 ■工程计价）。需要详细例题请看《计算专题手册》。

经济资金时间价值

① 一次支付终值 (F/P)F = P(1+i)n
② 一次支付现值 (P/F)P = F(1+i)−n
③ 等额终值 (F/A)F = A·[(1+i)n−1]/i
④ 偿债基金 (A/F)A = F·i/[(1+i)n−1]
⑤ 等额现值 (P/A)P = A·[(1+i)n−1]/[i(1+i)n]
⑥ 资本回收 (A/P)A = P·i(1+i)n/[(1+i)n−1]
有效年利率 m=计息次数i = (1+r/m)m − 1

经济经济效果评价

净现值 ≥0 可行NPV = Σ(CI−CO)t(1+ic)−t
净年值（寿命不同用它）NAV = NPV·(A/P,ic,n)
内部收益率（内插）IRR ≈ i₁+(i₂−i₁)·NPV₁/(NPV₁−NPV₂)
静态投资回收期Pt = (首个累计正值年−1) + 上年|累计|/当年净现金流
效益费用比 ≥1 可行R = PV(效益)/PV(费用)

经济不确定性 · 设备 · 价值工程

盈亏平衡产量Q* = CF/(p − cv − t)
生产能力利用率 BEPE* = Q*/Q设计 ×100%
敏感度系数 |S|大=敏感S = (ΔA/A)/(ΔF/F)
设备经济寿命（低劣化）N₀ = √(2(P−L)/λ)
价值 V<1 重点改进V = F/C　功能/成本

财务偿债能力

资产负债率= 负债总额 / 资产总额
流动比率 ≥2= 流动资产 / 流动负债
速动比率 ≥1= (流动资产−存货)/流动负债
利息备付率 ≥1= EBIT / 应付利息
偿债备付率 ≥1= (EBITDA−所得税)/应还本付息

财务营运 · 盈利能力

应收账款周转率 分子收入= 营业收入 / 平均应收账款
存货周转率 分子成本= 营业成本 / 平均存货
总资产报酬率= EBIT / 平均资产总额
净资产收益率= 净利润 / 平均净资产
资本金净利润率= 净利润 / 资本金

财务资金成本 · 营运资金

个别资金成本（税后）K = 年占用费(1−T)/[筹资额(1−f)]
加权平均资金成本Kw = Σ(Wj·Kj)
经济订货批量Q* = √(2·D·S/H)
最佳现金持有量总成本(持有+短缺+转换)最小

计价总投资构成

基本预备费= (工程费用+工程建设其他费)×费率
价差预备费 当年半年计PF = Σ It[(1+f)m(1+f)0.5(1+f)t−1−1]
建设期利息（当年借款半年计息）qj = (Pj−1 + Aj/2)·i
总投资= 建设投资 + 建设期利息 + 铺底流动资金

计价清单计价 · 造价合成

综合单价 不含规费税金= 人+材+机+企业管理费+利润(+风险)
分部分项工程费= Σ(工程量 × 综合单价)
单位工程造价= 分部分项+措施+其他+规费+税金
税金= 税前造价 × 增值税率

计价计量与支付

预付款起扣点T = P − M/N　M预付款 N主材比重
起扣后每次抵扣= 本期完成价款 × N
调值公式法 Σa=1P = P₀(a₀ + a₁A₁/A₀ + a₂B₁/B₀ + …)
