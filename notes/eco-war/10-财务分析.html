10.1 财务报告构成及列报基本要求▶
10.1.1 财务报告★★★★★2024·2025单选等高频▶

1. 财务报表的构成 2024·2025单选

资产负债表反映企业在某一特定日期财务状况（静态时点表）
利润表反映企业在一定会计期间经营成果（动态报表）
现金流量表反映企业一定会计期间现金和现金等价物流入和流出（动态报表）
所有者权益（或股东权益）变动表反映构成所有者权益（或股东权益）的各组成部分当期增减变动情况
附注对在上述各报表中列示项目的文字描述或明细资料，以及对未能在这些报表中列示项目的说明
财务报表：时点、期间与补充说明
静态时点
资产负债表：回答“某一特定日期，家底怎样”。
动态期间
利润表看经营成果；现金流量表看现金流入流出；权益变动表看当期权益增减。
文字补充
附注：解释报表已列项目，并说明未能列示的项目。
⚠ 资产负债表=特定日期（时点、静态）；利润表、现金流量表=一定会计期间（动态报表）——"日期/期间"互换是常见选项坑。

2. 资产负债表的内容 2018单选

  • 第一部分是资产类：按其"流动性"（即把资产转换成现金所需要的时间）大小顺序排列，分为流动资产和非流动资产列示
  • 第二部分是负债类：按债务必须支付的时间顺序排列，分为流动负债和非流动负债列示

3. 利润表的内容 2026修订

  • （1）营业收入 （2）营业利润 （3）利润总额 （4）净利润 （5）其他综合收益各项目分别扣除所得税影响后的净额 （6）综合收益总额

4. 现金及现金等价物 2016·2019多选 | 2026修订

现金库存现金、可以随时用于支付的存款、其他货币资金以及现金等价物。不能随时用于支付的存款不属于现金
现金等价物通常从购买日起三个月到期或清偿的国库券、货币市场基金、可转换定期存单、银行承兑汇票等都可列为现金等价物

5. 作为现金等价物的短期投资应满足的条件（四个条件） 2022单选

  • 期限短 · 流动性强 · 易于转换为已知金额的现金 · 价值变动风险小

6. 现金流量表的内容（三类活动） 2023单选 | 2018·2020·2025多选

经营活动①销售商品、提供劳务收到的现金；②收到的税费返还；③收到其他与经营活动有关的现金；④购买商品、接受劳务支付的现金；⑤支付给职工以及为职工支付的现金；⑥支付的各项税费；⑦支付其他与经营活动有关的现金
投资活动①收回投资收到的现金；②取得投资收益收到的现金；③处置固定资产、无形资产和其他长期资产收回的现金净额；④处置子公司及其他营业单位收到的现金净额；⑤收到其他与投资活动有关的现金；⑥购建固定资产、无形资产和其他长期资产支付的现金；⑦投资支付的现金；⑧取得子公司及其他营业单位支付的现金净额；⑨支付其他与投资活动有关的现金
筹资活动①吸收投资收到的现金；②取得借款收到的现金；③收到其他与筹资活动有关的现金；④偿还债务支付的现金；⑤分配股利、利润或偿付利息支付的现金；⑥支付其他与筹资活动有关的现金
口诀助记：经营活动关键词——商品、劳务、税费、职工、政府补助；投资活动关键词——投资、固定资产、无形资产、子公司；筹资活动关键词——吸收投资、取得借款、偿还债务、分配股利、利润、支付利息。
⚠ 归属易混：取得投资收益收到的现金→投资活动（不是筹资）；偿还债务、支付利息、分配股利→筹资活动；处置/购建固定资产→投资活动；收到税费返还→经营活动。

7. 资产负债表、利润表和现金流量表的作用

资产负债表①反映某一特定日期拥有的各种资源总量及分布情况，可以分析企业的资产构成，以便及时进行调整；②提供某一日期的负债总额及其结构，表明企业未来需要用多少资产或劳务清偿债务以及清偿时间；③反映特定日期所有者权益构成情况，可以判断资本保值、增值的情况以及对负债的保障程度
利润表①反映企业在一定期间的收入和费用情况以及获得利润或发生亏损的数额，表明企业投入与产出之间的关系；②可以分析判断企业损益发展变化的趋势，预测企业未来的盈利能力；③可以考核企业的经营成果及利润计划的执行情况，分析企业利润增减变化原因
现金流量表①有助于使用者对企业整体财务状况做出客观评价；②有助于评价企业的支付能力、偿债能力和周转能力；③有助于使用者预测企业未来的发展情况

8. 所有者权益（或股东权益）变动表的内容及其作用

内容①综合收益总额（合并报表中还应单独列示归属于母公司所有者的和归属于少数股东的综合收益总额）；②会计政策变更和前期差错更正的累积影响金额；③所有者投入资本和向所有者分配利润等；④按照规定提取的盈余公积；⑤所有者权益各组成部分的期初和期末余额及其调节情况
作用①全面反映了企业的所有者权益在年度内的变化情况；②便于会计信息使用者深入分析企业所有者权益的增减变化情况；③对企业的资本保值增值情况做出正确判断，从而提供对决策有用的信息

9. 财务报表附注的内容和作用

  • 内容：①企业的基本情况；②财务报表的编制基础；③遵循企业会计准则的声明；④重要会计政策和会计估计；⑤会计政策和会计估计变更以及差错更正的说明；⑥报表重要项目的说明；⑦或有和承诺事项、资产负债表日后非调整事项、关联方关系及其交易等需要说明的事项；⑧有助于评价企业管理资本的目标、政策和程序的信息；⑨关于其他综合收益各项目的信息等
  • 作用：是对财务报表的重要补充
10.1.2 财务报告列报基本要求★★★★2018·2021·2023单选 2020多选▶
  • 以持续经营为基础：根据实际发生的交易和事项，按照《企业会计准则》的规定进行确认和计量，在此基础上编制财务报表
  • 权责发生制编制：除现金流量表按照收付实现制原则编制外，企业应当按照权责发生制原则编制财务报表
  • 各会计期间保持一致，不得随意变更。两种除外情况：①会计准则要求改变财务报表项目的列报；②企业经营业务的性质发生重大变化或对企业经营影响较大的交易或事项发生后，变更列报能够提供更可靠、更相关的会计信息
  • 重要项目单独列报：从项目的性质和金额两方面予以判断；对各项目重要性的判断标准一经确定，不得随意变更
  • 报表列示项目不应相互抵销。三种情形不属于抵销：①一组类似交易形成的利得和损失以净额列示；②资产或负债项目按扣除备抵项目后的净额列示；③非日常活动产生的利得和损失，以同一交易形成的收益扣减相关费用后的净额列示更能反映交易实质的
  • 当期报表列报项目与上期报表列报项目应当具有可比性
  • 企业至少应当按年编制财务报表：期间短于一年的，应当披露年度财务报表的涵盖期间、短于一年的原因以及报表数据不具可比性的事实
  • 其他应披露的信息：编报企业的名称、资产负债表日或财务报表涵盖的会计期间、人民币金额单位、财务报表是合并财务报表的应予以标明
⚠ 只有现金流量表用收付实现制，其余报表一律权责发生制——"所有报表均按权责发生制编制"为错误说法；重要性判断看性质+金额两方面，"仅以金额大小判断"为错误说法；抵销后净额列报（三种情形）不属于"相互抵销"。
【2023年真题】根据《企业会计准则》，关于财务报表列报要求的说法，正确的是（　）
A.应以持续经营作为会计确认、计量和编制会计报表的基础　B.所有财务报表均应按照权责发生制编制　C.计入当期利润的利得和损失项目的金额应以抵消后的净额列报　D.重要项目单独列报，仅以项目金额大小为标准判断其重要性
答案：A。B错在现金流量表按收付实现制；C净额列示的三种情形不属于抵销但并非普遍要求；D应从性质和金额两方面判断。
10.2 财务分析方法▶
10.2.1 财务分析方法的分类★★★2016·2019·2020单选▶

1. 比率分析法

概念通过计算各种比率来确定经济活动变动程度的分析方法
常用的比率 ①构成比率：反映部分与总体的关系，如流动资产占资产总额的比率；
②相关比率：反映有关经济活动的相互联系、相互影响的关系，如资产净利率、存货周转率；
③动态比率：简便、直观。基期指数 = 分析期数额 / 基期数额 × 100%环比指数 = 分析期数额 / 前一期数额 × 100%
特点计算简便，计算结果比较容易判断，而且可以使某些指标在不同规模企业之间进行比较
⚠ 三种比率对号入座：部分/总体→构成比率；相互联系的不同指标相除（资产净利率、存货周转率）→相关比率；不同时期对比（基期指数、环比指数）→动态比率。

2. 因素分析法 2016·2019·2020单选

概念依据分析指标与其驱动因素之间的关系，从数量上确定各因素对分析指标的影响方向及程度的分析方法
连环替代法将分析指标分解为各个可以计量的因素，并根据各个因素之间的依存关系，顺次用各因素的比较值（通常为实际值）替代基准值（通常为标准值或计划值），据以测定各因素对指标的影响
差额计算法利用各因素的实际数与基准值之间的差额，计算各因素对分析指标的影响
【2020年真题】某企业产量（计划1000→实际1200件）、单位产品材料消耗量（8→7kg/件）、材料单价（50→55元/kg），用因素分析法（因素重要性按此顺序）计算材料费用总额的影响（　）　A.节约5万元 B.增加5万元 C.节约6.2万元 D.增加6万元
答案：C（书中标准答案）。连环替代过程：
①计划指标：1000×8×50=400000元；
②第一次替代（换产量）：1200×8×50=480000元；
③第二次替代（换单耗）：1200×7×50=420000元；
④第三次替代（换单价）：1200×7×55=462000元。
因素分析：产量增加的影响 ②−①=+8万元；材料消耗量节约的影响 ③−②=−6万元；价格提高的影响 ④−③=+4.2万元；全部因素的影响：8−6+4.2=6.2万元。核心方法：顺次只换一个因素、与上一步相减。
⚠ 连环替代顺序不可乱：按因素重要性顺次用实际值替代计划值，每一步只换一个因素，与上一步相减得该因素影响额。
10.2.2 财务比率分析★★★★★近十年单多选高频▶

1. 偿债能力比率 2019·2020·2022·2023·2025单选 2016多选

资产负债率 资产负债率 = 负债总额 / 资产总额 × 100% 50%比较合适（适度，并非越大或越小越好）。反映企业利用债权人提供资金进行经营活动的能力；反映企业经营风险的程度；综合反映企业长期偿债能力
权益乘数越大，表明所有者投入企业的资本占全部资产的比重越小，企业负债的程度越高；越小，所有者投入资本占比越大，负债程度越低，债权人权益受保护的程度就越高
流动比率 流动比率 = 流动资产 / 流动负债 一般认为生产性企业合理的最低流动比率为2；只适用于对短期偿债能力的粗略估计（越大偿债保障越强）
速动比率 速动比率 = 速动资产 / 流动负债 速动资产 = 流动资产 − 存货 速动资产 = 货币资金 + 交易性金融资产 + 应收票据 + 应收账款 + 其他应收款 反映企业的短期偿债能力；速动比率为1就说明企业有偿债能力，低于1则偿债能力不强；越低，偿债能力越差（越大越好）
利息备付率 利息备付率 = 息税前利润 / 当期应付利息 表明每1元当期应付利息支出有多少倍的息税前利润作为偿付保障；利息保障倍数越大，利息支付越有保障（越大越好）；反映企业长期偿债能力的指标；正常情况下应当大于1，一般情况下不宜低于2
偿债备付率 偿债备付率 = 可用于还本付息的资金 / 当期应还本付息金额 正常情况应当大于1（越大越好）；指标小于1时，表示企业当年资金来源不足以偿付当期债务，需通过短期借款偿付已到期债务；一般情况下不宜低于1.3。
可用于还本付息的资金一般包括：未分配利润（提取了盈余公积、公益金并向股东支付完股利之后的未分配利润）、固定资产折旧、无形资产及其他资产摊销费；运营期内用于维持运营的投资应扣除；当期应还本付息金额包括当期应还贷款本金额及计入总成本费用的全部利息；融资租赁费用可视同借款偿还；运营期的短期借款本息也应纳入计算
⚠ 流动比率 vs 速动比率：分母同为流动负债，区别在分子——速动资产要剔除存货；参考值也不同（流动比率≥2，速动比率≥1）。
⚠ 长短期指标别站错队：资产负债率、权益乘数、利息备付率→长期偿债能力；流动比率、速动比率→短期偿债能力。申请短期贷款时资产负债率不予考虑（2023真题考点）。
⚠ 底线数字：利息备付率正常>1、不宜低于2；偿债备付率正常>1、不宜低于1.3——两个"不宜低于"易互换设坑。资产负债率50%比较合适（适度型指标）。
【2025年真题】营业收入1100万，息税前利润500万，税前利润420万，税后利润315万，当期应付利息80万，利息备付率为（　）
答案：C（6.25）。利息备付率=息税前利润/当期应付利息=500/80=6.25。注意用息税前利润，不是税前或税后利润。
【2023年真题】运营期第6年：利息备付率5，息税前利润5000万，应偿还借款本金3000万，折旧3000万，摊销费100万，利润总额4000万（无需弥补前年度亏损），所得税率25%。第6年偿债备付率为（　）
答案：A（1.78）。当期应付利息=息税前利润/利息备付率=5000/5=1000万；可用于还本付息资金=未分配利润+折旧+摊销+利息=4000×(1−25%)+3000+100+1000=7100万；应还本付息=3000+1000=4000万；偿债备付率=7100/4000≈1.78。
【2023年真题】四家企业申请短期贷款：甲（流动2.3/速动1.2/资产负债率60%）、乙（2.1/1.4/65%）、丙（2.3/1.5/70%）、丁（1.9/1.3/50%），银行应优先贷给（　）
答案：A（丙）。申请短期贷款，资产负债率是长期偿债能力指标不予考虑，只比流动比率和速动比率。丙的流动比率和速动比率都比甲、乙、丁高，说明其短期偿债能力最强，应优先贷款给丙。

2. 营运能力比率 2017·2018·2020·2024单选 2017·2020多选

总资产周转率 总资产周转率（次数）= 营业收入 / [（期初资产总额 + 期末资产总额）÷ 2] 指标越高，反映企业销售能力越强（越大越好）
流动资产周转率 流动资产周转次数 = 营业收入 / [（期初流动资产 + 期末流动资产）÷ 2] 流动资产周转天数 = 计算期天数 / 流动资产周转次数 周转次数表明1年中流动资产周转的次数，或说明1元流动资产支持的主营业务收入；周转天数表明流动资产周转1次需要的时间，即转换成现金平均需要的时间
存货周转率 存货周转次数 = 营业收入或营业成本 / [（期初存货 + 期末存货）÷ 2] 存货周转天数 = 计算期天数 / 存货周转次数 周转次数越多、周转天数越短，说明该指标越好；周转次数低或下降、周转天数长，可能意味着存货中残次品增加。存货周转天数也不是越短越好——存货过少占用资金越多（影响生产供应），应基于企业的生产条件等确定合理的存货周转天数
应收账款周转率 应收账款周转率（周转次数）= 营业收入 / [（期初应收账款 + 期末应收账款）÷ 2] 应收账款周转天数 = 365 / 应收账款周转次数 既反映应收账款的变现速度，又反映企业的管理效率；指标越高、周转天数越短越好，表明收回速度快，可以节约资金，也说明企业信用状况好，不易发生坏账损失
口诀助记：管理的好周转就快，关键词"周转"。分母都是（期初+期末）÷2 的平均占用额。
⚠ 存货周转天数并非越短越好（要结合生产条件确定合理水平）——与"越短越好"的绝对化说法区分；存货周转次数分子可用营业收入或营业成本，其他周转率分子只用营业收入。
【2024年真题】某企业2023年营业收入6000万元，年初应收账款600万元，年末800万元，应收账款周转率为（　）
答案：C（8.57）。应收账款周转率=6000/[(600+800)÷2]=6000/700≈8.57次。

3. 盈利能力比率 2016单选 2018多选

权益净利率 也称净资产收益率，核心指标 权益净利率 = 净利润 / [（期初股东权益总额 + 期末股东权益总额）÷ 2 ] × 100% 指标越高，表明股东权益的利用效率越高，说明企业在增加收入和节约资金使用等方面取得了良好的效果（越大越好）
总资产净利率 总资产净利率 = 净利润 / [（期初资产总额 + 期末资产总额）÷ 2 ] × 100% 指标越高，表明企业资产的利用效率越高，盈利能力越强（越大越好）
⚠ 盈利能力比率分子都是净利润；权益净利率=净资产收益率是核心指标——与总资产净利率的分母（股东权益 vs 资产总额）区分。

4. 发展能力比率 2021·2023单选 2024多选

营业收入增长率 营业增长率 = 本期营业收入增加额 / 上期营业收入总额 × 100% ①评价企业成长状况和发展能力的重要指标；②衡量企业经营状况和市场占有能力、预测企业经营业务拓展趋势的重要标志；③企业扩张资本的重要前提；④指标越高，表明营业收入增长速度越快，企业市场前景越好（越大越好）
资本积累率 资本积累率 = 本年度所有者权益增长额 / 年初所有者权益 × 100% ①体现了企业资本的积累能力；②是评价企业发展潜力的重要指标，也是企业扩大再生产的源泉；③反映了投资者投入企业资本的保全性和增长性；④指标越高，表明企业的资本积累越多，企业资本保全性越强，应对风险、持续发展的能力越大（越大越好）
口诀助记：积累增长就能发展。（增长率分母是"上期总额"，积累率分母是"年初所有者权益"）
