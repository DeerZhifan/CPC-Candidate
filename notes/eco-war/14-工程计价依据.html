14.2 人工、材料与施工机具台班消耗量确定▶
14.2.1 人工定额消耗量确定★★★★★2023单选等高频▶
1. 人工定额编制的主要工作
  • 拟定正常的施工作业条件：拟定施工作业的内容、方法、地点的组织、人员的组织
  • 测定定额时间：通过计时观察、大数据分析等方法获得定额的各种必需消耗的时间
  • 口诀：什么人、在什么地点、用什么方法、做什么事
2. 人工定额的确定方法2023单选
技术测定法根据生产技术和施工组织条件，对施工过程中各工序采用测时法、写实记录法、工作日写实法，测出各工序的工时消耗等资料，再对所获得的资料进行科学的分析，制定出人工定额
统计分析法简单易行，适用于施工条件正常、产品稳定、工序重复量大和统计工作制度健全的施工过程
比较类推法对于同类型产品规格多、工序重复、工作量小的施工过程常用
经验估计法通常作为一次性定额使用
  • 口诀：比统经技
3. 工人工作时间消耗的分类2016~2025多年单/多选
必需消耗的时间（计入定额）
有效工作时间基本工作时间、准备与结束工作时间、辅助工作时间
休息时间计入定额
不可避免的中断时间计入定额
损失时间（不计入定额）
多余和偶然工作时间—
停工时间施工本身造成的停工时间 / 非施工本身造成的停工时间
违背劳动纪律损失时间—
⚠ 停工时间虽属损失时间，但编制定额时：非施工本身造成的停工（如水源、电源中断）应合理考虑并予以计算；施工本身造成的停工（组织不当、供料不及时等）不予计算。
【2025真题】编制人工定额时，应合理考虑并予以计算的停工时间是（ ）
答案 B：由于水源或电源中断引起的停工时间（非施工本身造成）。A劳动组织不合理、C材料供应不及时、D技术人员和工人差错均为施工本身造成，不计算。
4. 确定人工定额消耗量
定额时间 = 基本工作时间 + 辅助工作时间 + 准备与结束工作时间 + 不可避免的中断时间 + 休息时间
5. 人工定额的形式（表14-3）
按表现形式时间定额
单位产品时间定额（工日）= 1 / 每工日产量
或 单位产品时间定额（工日）= 小组成员工日数总和 / 机械台班产量
产量定额
产量定额 = 1 / 时间定额
按定额的标定对象单项工序定额
综合时间定额 = Σ各单项（工序）时间定额
综合定额
综合产量定额 = 1 / 综合时间定额（工日）
⚠ 时间定额与产量定额互为倒数；综合时间定额是各工序时间定额之和（不是倒数相加），综合产量定额再取其倒数。
14.2.2 材料定额消耗量的确定★★★2018·2021单选 2017多选▶
1. 施工中的材料
  • 可分为：必需的材料消耗（直接用于建筑和安装工程的材料净用量 + 不可避免的施工废料 + 不可避免的材料损耗）与 损失的材料
  • 又可分为：实体材料（直接构成工程实体的材料，含工程直接性材料和辅助材料）与 非实体材料（施工中必须使用但不能构成工程实体的施工措施性材料，主要指周转性材料，如模板、脚手架、支撑等）
2. 实体材料定额消耗量确定方法
理论计算法根据设计、施工验收规范和材料规格等，从理论上计算材料净用量。标准砖：
A = 1 / [墙厚 × (砖长+灰缝) × (砖厚+灰缝)] × K（块）
K = 墙厚的砖数 × 2（0.5砖墙、1砖墙、1.5砖墙……）
标准砖（砂浆）总消耗量 = 净用量 × (1+损耗率)
实验室试验法主要用于编制材料净用量定额；能更详细地研究各种因素对材料消耗的影响；缺点是无法估计施工现场因素对材料消耗量的影响
现场技术测定法主要适用于确定材料损耗量，通过现场观察区分出哪些是可以避免的损耗、哪些是难以避免的损耗；定额中不应列入可以避免的损耗
现场统计法以施工现场积累的分部分项工程使用材料数量、完成产品数量、完成工作原材料的剩余数量等统计资料为基础，经过整理分析获得材料消耗的数据
3. 非实体材料（周转性材料）定额消耗量确定2018单选 2017多选
  • 四个因素：①第一次制造时的材料消耗（一次使用量）②每周转使用一次材料的损耗（第二次使用时需要补充）③周转使用次数 ④周转材料的最终回收及其回收折价
  • 两个指标：一次使用量——供施工企业组织施工用；摊销量——供施工企业成本核算或投标报价使用
4. 模板用量的计算（表14-4）2016·2021单选
现浇混凝土结构木模板
一次使用量 = 净用量 × (1+操作损耗率)
周转使用量 = 一次使用量 × [1+(周转次数−1)×补损率] / 周转次数
回收量 = 一次使用量 × (1−补损率) / 周转次数
摊销量 = 周转使用量 − 回收量 × 回收折价率
预制混凝土构件的模板
一次使用量 = 净用量 × (1+操作损耗率)
摊销量 = 一次使用量 / 周转次数
⚠ 现浇模板摊销量 = 周转使用量 − 回收量×回收折价率（要扣回收）；预制构件模板直接一次使用量÷周转次数（不计补损率、不扣回收）。两套公式常互换设坑。
【2021真题】木模板一次净用量200m²，操作损耗2%，周转5次，每次补损率5%，周转使用量为（ ）m²
答案 B：48.96。一次使用量=200×(1+2%)=204m²；周转使用量=[204×(1+4×5%)]/5=48.96m²。
14.2.3 施工机具定额台班消耗量确定★★★★2016~2023多年单选 2019多选▶
1. 机械工作时间消耗的分类
必需消耗的时间
有效工作时间正常负荷下的工作时间、有根据地降低负荷下的工作时间
不可避免的无负荷工作时间如筑路机在工作区末端调头
不可避免的中断时间与工艺过程的特点有关、与机械有关、工人休息时间
损失时间
多余工作时间如工人没有及时供料而使机械空运转
停工时间施工本身造成的停工时间 / 非施工本身造成的停工时间
违背劳动纪律时间—
低负荷下工作的时间如工人装车的砂石数量不足引起的降低负荷工作
⚠ 机械比人工多两类：不可避免的无负荷工作时间（必需消耗）与低负荷下的工作时间（损失时间）。"有根据地降低负荷"（如货物轻而体积大不能满载）属于有效工作时间；"低负荷"（装料不足）属于损失时间——一字之差，年年设坑。
2. 机械工作时间消耗示例判定（表14-5）
示例时间归类
汽车运输重量轻而体积大的货物，不能充分利用载重吨位有根据地降低负荷下的工作时间
筑路机在工作区末端调头不可避免的无负荷工作时间
灰浆泵由一个工作地点转移到另一工作地点时的工作中断与工艺过程的特点有关的不可避免中断工作时间
工人没有及时供料而使机械空运转的时间机械的多余工作时间
由于未及时供给机械燃料而引起的停工施工本身造成的停工时间
暴雨时压路机的停工非施工本身造成的停工时间
工人装车的砂石数量不足引起的汽车降低负荷工作所延续的时间低负荷下的工作时间
【2021真题】筑路机在工作区末端调头所消耗的时间，属于施工机械工作时间中的（ ）
答案 D：不可避免的无负荷工作时间。
3. 施工机具台班定额消耗量的确定（表14-6）
  • 确定机械1h纯工作正常生产率：
    循环动作机械：一次循环的正常延续时间 = Σ循环各组成部分正常延续时间 − 交叠时间
    机械纯工作1h循环次数 = 60×60(s) / 一次循环的正常延续时间
    机械纯工作1h正常生产率 = 纯工作1h循环次数 × 一次循环生产的产品数量
    连续动作机械纯工作1h正常生产率 = 工作时间内生产的产品数量 / 工作时间(h)
  • 确定施工机械的时间利用系数：
    机械时间利用系数 = 机械在一个工作班内纯工作时间 / 一个工作班延续时间(8h)
  • 计算施工机械台班定额：
    施工机械台班产量定额 = 机械1h纯工作正常生产率 × 工作班纯工作时间
    或 = 机械1h纯工作正常生产率 × 工作班延续时间 × 机械时间利用系数
【经典例题】斗容量1m³正铲挖掘机台班产量480m³，配备两名工人，机械利用系数0.8，正常条件下机械1h纯工作时间可挖土（ ）m³
答案 D：75。1h纯工作生产率 = 480 / (8×0.8) = 75m³。
4. 施工机械台班使用定额的表现形式（表14-7）
施工机械时间定额
单位产品机械时间定额（台班）= 1 / 台班产量
单位产品机械时间定额（工日）= 小组成员总人数 / 台班产量
机械产量定额
机械台班产量定额 = 1 / 机械时间定额（台班）
【经典例题】某机械台班产量4m³，配合的工人小组5人，则单位产品的人工时间定额为（ ）工日
答案 A：1.25。人工时间定额 = 小组总人数/台班产量 = 5/4 = 1.25工日。
14.3 人工、材料与施工机具台班单价确定▶
14.3.1 人工日工资单价确定方法★★★2019多选▶
  • 确定年平均每月法定工作日：
    年平均每月法定工作日 = (全年日历日 − 法定假日) / 12
  • 计算人工日工资单价：
    日工资单价 = [生产工人平均月工资(计时、计件) + 平均月(奖金+津贴补贴+特殊情况下支付的工资)] / 年平均每月法定工作日
  • 确定日工资单价应根据工程项目的技术要求，通过市场调查、参考实物工程量人工单价综合分析确定；最低日工资单价不得低于工程所在地人力资源和社会保障部门发布的最低工资标准
  • 工程计价定额不可只列一个综合工日单价，应根据工程项目技术要求和工种差别适当划分多种人工日工资单价，确保各分部工程人工费的合理构成
14.3.2 材料单价确定方法★★★★2016·2018·2024·2025单选▶
材料原价
（或供应价格）		国内采购材料的出厂价格；国外采购材料抵达买方边境、港口或车站并交纳完各种手续费、税费（不含增值税）后形成的价格。有几种价格（原价）时，采取加权平均：
加权平均原价 = (K₁C₁+K₂C₂+…+KₙCₙ) / (K₁+K₂+…+Kₙ)
K——各不同供应地点的供应量或各不同使用地点的需要量；C——各不同供应地点的原价
材料运杂费国内采购材料自来源地、国外采购材料自到岸港运至工地仓库或指定堆放地点发生的费用（不含增值税）。含外埠中转运输过程中所发生的一切费用和过境过桥费用，包括调车和驳船费、装卸费、运输费及附加工作费等。
若运输费用为含税价格，按两种支付方式分别调整：
"两票制"：材料销售价/(1+13%) 和 运输服务费/(1+9%)；
"一票制"：材料价格/(1+13%)
运输损耗
运输损耗 = (材料原价+运杂费) × 运输损耗率(%)
采购及保管费组织采购、供应和保管材料过程中所需要的各项费用，包含：采购费、仓储费、工地保管费和仓储损耗
材料单价 = (材料原价+运杂费) × [1+运输损耗率(%)] × [1+采购保管费率(%)]
⚠ 两票制材料13%、运费9%分别除税；一票制整体按13%除税。运输损耗按（原价+运杂费）取率，采购保管费再在其外层连乘——顺序不能颠倒。
【2024真题】材料出厂价4000元/吨，运输费100元/吨，运输损耗率1%，采购保管费率2%（均不含税），该材料单价为（ ）元/吨
答案 D：4223.82。(4000+100)×1.01×1.02 = 4223.82元/吨。
14.3.3 施工机械台班单价确定方法★★★★2022·2023·2024·2025单选▶
折旧费
台班折旧费 = 机械预算价格 × (1−残值率) / 耐用总台班
耐用总台班 = 折旧年限 × 年工作台班 = 检修间隔台班 × 检修周期
检修周期 = 检修次数 + 1
检修费
台班检修费 = (一次检修费 × 检修次数 / 耐用总台班) × 除税系数
维护费
台班维护费 = [Σ(各级维护一次费用 × 除税系数 × 各级维护次数) + 临时故障排除费] / 耐用总台班
各项数值难以确定时：维护费 = 检修费 × K（K为维护费系数，指维护费占检修费的百分数）
安拆费及场外运费 (1) 计入台班单价：安拆简单、移动需要起重机运输的轻型施工机械
台班安拆费及场外运费 = 一次安拆费及场外运费 × 年平均安拆次数 / 年工作台班
(2) 单独计算：①安拆复杂、移动需要起重机运输的重型施工机械 ②利用辅助设施移动的施工机械（辅助设施如轨道和枕木等的折旧、搭设和拆除费用可单独计算）③自升式塔式起重机、施工电梯安拆费的超高起点及其增加费，各地区、部门可根据具体情况确定
(3) 不需计算：①不需安拆的施工机械，不计算一次安拆费 ②不需相关机械辅助运输的自行移动机械，不计算场外运费 ③固定在车间的施工机械，不计算安拆费及场外运费
人工费
台班人工费 = 人工消耗量 × [1+(年制度工作日−年工作台班)/年工作台班] × 人工单价
台班燃料动力费
台班燃料动力费 = Σ(台班燃料动力消耗量 × 燃料动力单价)
台班燃料动力消耗量 = (实测数×4 + 定额平均值 + 调查平均值) / 6
其他费用
台班其他费用 = (年车船税+年保险费+年检测费) / 年工作台班
⚠ 检修周期 = 检修次数+1（不是检修次数）；折旧、检修、维护费分母都是耐用总台班，安拆费和其他费用分母是年工作台班。安拆费三档：轻型→计入台班单价、重型/辅助设施/塔机超高→单独计算、不需安拆/自行移动/固定车间→不计算。
【2024真题】机械预算价格48万元，使用年限10年，年平均工作220台班，净残值率5%，该机械台班折旧费为（ ）元
答案 A：207.27。480000×(1−5%)/(10×220) = 207.27元。
14.3.4 施工仪器仪表台班单价确定方法★★★▶
折旧费
仪器仪表台班折旧费 = 施工仪器仪表原值 × (1−残值率) / 年工作台班
维护费
仪器仪表台班维护费 = 年维护费 / 年工作台班
校验费
仪器仪表台班校验费 = 年校验费 / 年工作台班
动力费
仪器仪表台班动力费 = 台班耗电量 × 电价
⚠ 仪器仪表台班单价只含4项：折旧费、维护费、校验费、动力费；且折旧费分母是年工作台班——区别于施工机械折旧费分母的耐用总台班。
14.4 预算定额、概算定额与概算指标▶
14.4.1 预算定额及其基价★★★★2017·2019·2024单选 2025多选▶
1. 预算定额的作用与编制原则
  • 作用：是编制施工图预算、确定建筑安装工程造价的基础；是编制最高投标限价的基础；是编制施工组织设计、进行经济分析的依据；是编制概算定额的基础
  • 编制原则：按社会平均水平确定；简明适用
2. 人工消耗量指标的确定2017·2019单选
  • 基本用工：完成分项工程的主要用工量
  • 其他用工：①超运距用工——超过人工定额规定的材料、半成品运距的用工 ②辅助用工——材料需在现场加工的用工 ③人工幅度差用工——施工定额中未包括的、正常施工情况下又不可避免的一些零星用工
  • 人工幅度差用工内容：各种专业工种之间的工序搭接及土建工程与安装工程的交叉、配合中不可避免的停歇时间；施工机械在场内单位工程之间变换位置及移动临时水电线路引起的临时停水、停电所发生的不可避免的间歇时间；施工过程中水电维修用工；隐蔽工程验收等工程质量检查影响的操作时间；现场内单位工程之间操作地点转移影响的操作时间；施工过程中工种之间交叉作业造成的不可避免的剔凿、修复、清理等用工；施工过程中不可避免地直接少量零星用工
  • 计算（第一步综合取定工程量——预算定额是一项综合性定额；第二步计算人工消耗量）：
    基本用工数量 = Σ(工序工程量 × 时间定额)
    超运距用工数量 = Σ(超运距材料数量 × 时间定额)，超运距 = 预算定额规定的运距 − 劳动定额规定的运距
    辅助用工数量 = Σ(加工材料数量 × 时间定额)
    人工幅度差用工数量 = (基本用工+超运距用工+辅助用工) × 人工幅度差系数
    人工消耗量 = (基本用工+辅助用工+超运距用工) × (1+人工幅度差系数)
【2019真题】基本用工15工日，超运距用工3工日，辅助用工2工日，人工幅度差系数10%，人工幅度差用工数量为（ ）工日
答案 D：2.0。(15+3+2)×10% = 2.0工日。
3. 材料耗用量指标的确定
  • 以材料消耗定额为基础，按预算定额的定额项目，综合材料消耗定额的相关内容，经汇总后确定
4. 机械台班消耗指标的确定2025多选
  • 以台班为单位计算，每一台班为8h工作制；按合理的施工方法取定并考虑增加了机械幅度差
  • 机械幅度差内容：①施工机械转移工作面及配套机械互相影响损失的时间 ②正常施工情况下机械施工中不可避免的工序间歇 ③检查工程质量影响机械操作的时间 ④临时水、电线路在施工中移动位置所发生的机械停歇时间 ⑤工程结尾时，工作量不饱满所损失的时间
5. 预算定额基价的确定2024单选
  • 预算定额基价是预算定额分项工程或定额子目的单价，只包括人工费、材料费和施工机具使用费，即工料单价
  • 编制本质上是编制人、材、机的消耗量和人、材、机的单价的综合过程；一般通过编制单位估价表来确定单价，用于直接编制施工图预算
  • 应是地区定额基价，应按当地的资源价格来编制；是动态变化的，应随市场价格变化不断调整、修改和补充；以一个城市或一个地区为范围进行编制，在该地区范围内适用
  • 编制：①以全国统一或地区通用的预算定额或基础定额确定人、材、机台班的消耗量 ②以本地区或市场上的资源实际价格或市场价格确定人、材、机台班价格
  • 项目的划分、名称、编号、计量单位和工程量计算规则上应尽量与预算定额保持一致；单价均为不含增值税进项税额的价格
⚠ 预算定额基价 = 工料单价（人工费+材料费+施工机具使用费），不含企业管理费、利润、规费、税金——选项常混入"全费用单价"设坑。
14.4.2 概算定额及其基价★★★▶
  • 作用：是编制初步设计阶段工程概算、扩大初步设计阶段修正概算的主要依据；是对设计项目进行技术经济分析比较的基础资料之一；是编制建设工程主要材料计划的依据；是控制施工图预算和最高投标限价的依据；是工程结束后进行竣工决算和项目评价的依据；是编制概算指标的依据
  • 编制原则：编制深度要适应设计深度的要求；定额水平的确定应与全国统一或地区通用的预算定额或基础定额的水平基本一致
  • 编制方法：在预算定额的基础上综合而成，每一项概算定额项目都包括了数项预算定额的定额项目
14.4.3 概算指标★★★▶
  • 作用：是初步设计阶段编制概算、确定工程概算造价的依据；可以作为编制投资估算的参考；主要材料指标可以作为匡算主要材料用量的依据；是设计单位进行设计方案比较、设计技术经济分析的依据；是编制固定资产投资计划、确定投资额和主要材料计划的主要依据
  • 分类：建筑工程概算指标、设备及安装工程概算指标
  • 编制方法：是概算定额的扩大与合并，以整个房屋或构筑物为对象、以更为扩大的计量单位来编制；包括人工、材料和机械台班定额三个基本部分；列出了各结构分部的工程量及单位工程（以体积计或以面积计）的造价
⚠ 三者对象与用途梯度：预算定额→分项工程/结构构件→施工图预算；概算定额→扩大分项工程→设计概算（以预算定额为基础综合）；概算指标→单位工程/整个房屋构筑物→初步设计概算（概算定额的扩大与合并）。"谁是谁的编制基础"是高频考点：施工定额→预算定额→概算定额→概算指标。
