2.2.2 投资回收期分析★★★★2017·2018·2019·2023单选 | 2022多选▶
  • 若方案只有初始投资 I（发生在第1年初），且计算期内各年净现金流量 A 保持不变：
    Pt = I / A
  • 一般公式：
    Pt = (累计净现金流量首次出现正值或零的年份数 − 1) + 上一年累计净现金流量的绝对值 / 出现正值年份的净现金流量
判别准则（1）静态投资回收期 Pt ≤ 基准投资回收期 Pc，则可以考虑接受
（2）Pt > 基准投资回收期 Pc，则方案是不可行的
⚠ 公式分子是"上一年累计净现金流量的绝对值"，分母是"出现正值当年的（当年）净现金流量"——分子分母年份错位是常设选项坑。
【2023真题】现金流量表：流出第1~7年为560/270/80/150/220/230/250，流入第4~7年为130/260/450/480/550（第3年末流入130），求静态投资回收期
答案 C：6.63年。逐年累计净现金流量在第7年首次转正，Pt = (7−1) + 上年累计亏损绝对值/第7年净现金流量 ≈ 6.63。
2.2.3 财务净现值分析★★★★★2018~2021·2023·2024单选 | 2022多选▶
1. 财务基准收益率的确定
本质是投资资金应当获得的最低盈利率水平
考虑因素一定时期内国家和行业发展战略、发展规划、产业政策、资源供给、市场需求、自身的发展战略、经营策略、方案的特点与风险，资金成本、机会成本、投资风险和通货膨胀率
2. 财务净现值（FNPV）分析
概念直接用货币单位表示的绝对指标，是反映方案在计算期内的盈利能力的动态指标
计算
FNPV = Σt=0n (CI − CO)t (1 + ic)−t
(CI−CO)t——第 t 年净现金流量（注意"+""−"号）；ic——设定的折现率（一般采用财务基准收益率）；n——方案计算期
判别标准FNPV > 0，方案在财务上可行；FNPV = 0，方案在财务上也是可行的；FNPV < 0，方案在财务上不可行
⚠ FNPV = 0 时方案"也是可行的"——不要误判为不可行；FNPV是"绝对指标+动态指标"，两属性常拆开考。
【2025真题】现金流量（年末）：流出第1~6年 2200/4000/2000/2500/2500/3000，流入第2~6年 1000/4500/3000/5500/5000，折现率8%，求FNPV
答案 B：1045.131万元。净现金流量 −2200/−3000/2500/500/3000/2000，按8%逐年折现求和：FNPV = −2200/1.08 − 3000/1.08² + 2500/1.08³ + 500/1.08⁴ + 3000/1.08⁵ + 2000/1.08⁶ = 1045.131万元。
2.2.4 财务内部收益率分析★★★★★2016·2019·2021·2024·2025单选 | 2018多选▶
1. 财务内部收益率（FIRR）分析
概念使方案在计算期内各年净现金流量的现值累计等于零时的折现率：
FNPV(FIRR) = Σt=0n (CI − CO)t × 1/(1 + ir)t = 0
随着折现率的逐渐增大，财务净现值由大变小
判断（1）FIRR ≥ 基准收益率 ic，方案在经济上可以接受
（2）FIRR < 基准收益率 ic，方案在经济上应予拒绝
2. 财务净现值与财务内部收益率的关系
FIRR ≈ i1 + FNPV1 / (FNPV1 + |FNPV2|) × (i2 − i1)
  • i 增大，净现值减小；i 减小到净现值 = 0 时，i 值就是财务内部收益率
  • 基准收益率越大，财务净现值越小
折现率—净现值—内部收益率关系
折现率 i ↑折现力度加大
FNPV ↓由正逐渐变负
FNPV = 0此时 i = FIRR
与 ic 比较FIRR ≥ ic 可接受
⚠ FIRR的取值区间：FNPV由正变负所夹的折现率区间内。如 i=7% 时 FNPV=+150，i=9% 时 FNPV=−80，则 8%附近需再判断：内插值更靠近净现值绝对值小的一端——考题只要求区间时选"正负变号"的两点之间。
【2025真题】折现率7%时FNPV=150万元，9%时FNPV=−80万元，FIRR取值范围？
答案 C：大于8%，小于9%。内插：FIRR ≈ 7% + 150/(150+80) × 2% ≈ 8.3%，落在8%~9%之间。
【2024真题】原方案建设期2年、运营期10年，FIRR=17.67%；追加建设投资使建设期第1年年初现金流出增加40000万元，运营期前4年每年净流入增加10000万元，FIRR可能变为？
答案 A：15.00%。按17.67%折现增量现金流：−40000 + 10000/(1.1767)³⁻⁶合计 = −23751.411万元 < 0，说明追加投资后FIRR小于17.67%，只有A符合。
3. 经济效果评价指标的优劣 2017·2019·2020单选
指标优点缺点
静态投资回收期（1）计算简单，容易理解（2）反映方案原始投资的补偿速度和方案投资风险大小（1）没有全面考虑方案整个计算期内的现金流量，只考虑回收之前的效果，无法准确衡量方案在整个计算期内的经济效果（2）只能作为辅助评价指标，或与其他评价指标结合应用
财务净现值（1）考虑了资金的时间价值，并全面考虑方案在整个计算期内现金流量的时间分布的状况（2）经济意义明确直观（3）能够直接以货币额表示方案的盈利水平（1）必须首先确定一个符合经济现实的折现率或财务基准收益率（2）不能直接反映方案单位投资的收益水平（3）不能反映方案投资回收的速度
财务内部收益率（1）考虑了资金的时间价值以及在整个计算期内的现金流量（2）大小完全取决于方案投资过程净现金流量系列的情况，不受外部参数影响（1）计算麻烦（2）值不存在或多解
⚠ 优劣对比坑：FNPV需要"先定折现率"，FIRR"不受外部参数影响"——两者正好相反；FIRR的缺点是可能"不存在或多解"。
2.3 多方案比选▶
2.3.1 方案之间的关系★★★2026修订▶
独立关系各个方案的现金流量是独立的，各方案之间不具有相关性，其中任一方案的采用与否与自身的可行性有关，而与其他方案采用与否没有关系
分为无约束条件和有约束条件两种情况：无约束条件情况下，备选方案只需满足绝对效果分析的评判标准即可入选
互斥关系在各个备选方案中只能选择一个，其余的均必须放弃，不能同时存在；要求备选方案可以相互替代
相关关系某一方案的采用与否对其他方案的现金流量带来一定的影响，进而影响其他方案的采用或拒绝
2.3.2 方案比选方法的类型★★★▶
划分标准类型
按比选范围不同局部比选、整体比选
按比选所应用模型工具不同定性比选、定量比选
2.3.3 方案比选定量分析方法的选择★★★2024·2025单选 | 2026修订▶
独立方案实质是在"做"与"不做"之间做出选择
互斥方案评价指标直接对比法 要求所选用的指标是价值型
① 计算期相同：常用财务净现值、净年值、费用现值、费用年值等。FNPV指标评价步骤：先分别计算各方案FNPV，剔除 FNPV<0 的方案（绝对效果检验）；再对所有 FNPV≥0 的方案比较，选择财务净现值最大的方案为最佳方案。判据：财务净现值不小于零且为最大的方案是最优可行方案，可同时满足绝对效果评价和相对效果评价的要求
② 计算期不同：处理方法包括年值法、最小公倍数法和研究期法等。年值法：以 AW ≥ 0 且 AW 最大者为最优方案；最小公倍数法（又称方案重复法）：以财务净现值较大的方案为优；研究期法：以财务净现值较大的为优
增量指标分析法 常用增量指标：增量财务净现值、增量投资财务内部收益率、增量静态投资回收期等
基本计算步骤：①将方案按照投资额从小到大的顺序排列；②确定基础方案，即满足指标评判准则要求的投资额较小的方案，也称临时最优方案，作为整个方案序列计算的基础；③计算相邻两个方案的增量现金流量的评价指标，若满足评判准则的要求，则投资较大的方案优于投资较小的方案；若不满足，则投资较小的方案优于投资较大的方案，投资较大的方案被淘汰；④以确定的较优方案为基础方案，重复计算步骤；⑤最后确定最优方案优选序列
相关方案在没有资金约束时，只要各方案本身的 FNPV ≥ 0 或 FIRR ≥ ic，方案就可行。但在有资金限制时，可采用上述互斥方案比选方法进行比选
⚠ 计算期不同的互斥方案不能直接比FNPV！须用年值法/最小公倍数法/研究期法；年值法判据是 AW≥0 且最大。
⚠ 增量分析法两个高频坑：①按投资额"从小到大"排列（不是从大到小）；②基础方案是满足判据的"投资额较小"的方案。
【2025真题】甲、乙为计算期不同的互斥方案，均可行；甲的FNPV大于乙、静态投资回收期长于乙、FIRR大于乙、等额年值小于乙。两方案比选说法正确的是？
（答案在书第014页，超出本次整理页范围）解析要点：计算期不同的互斥方案应采用年值法比选，等额年值大者为优——乙的等额年值大于甲，故乙方案较优；不能因甲FNPV大而直接选甲。
