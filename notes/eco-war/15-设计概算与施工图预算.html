15.1 设计概算编制▶
15.1.1 设计概算定义和作用★★★▶
定义设计概算是在建设项目初步设计阶段形成的设计概算成果文件——设计概算书，也简称设计概算或总概算书
作用 ① 是确定和控制建设项目全部投资的文件；
② 是编制固定资产投资计划、实行建设项目投资包干、签订承发包合同的依据；
③ 是签订贷款合同、项目实施全过程造价管理以及考核项目经济合理性的依据；
④ 经投资主管部门或其他有关部门核定的设计概算是控制政府投资项目总投资的依据
15.1.2 设计概算编制依据★★★▶
  • 国家、行业和地方有关规定
  • 相应工程造价管理机构发布的概算定额（或指标）
  • 工程勘察与设计文件
  • 拟定或常规的施工组织设计和施工方案
  • 建设项目资金筹措方案
  • 工程所在地编制同期的人工、材料、机械台班市场价格，以及设备供应方式及供应价格
  • 建设项目的技术复杂程度，新技术、新材料、新工艺以及专利使用情况等
  • 建设项目批准的相关文件、合同、协议等
  • 政府有关部门、金融机构等发布的价格指数、利率、汇率、税率以及工程建设其他费用等
  • 委托单位提供的其他技术经济资料
15.1.3 设计概算的编制工作程序★★★▶

收集原始资料 → 确定有关数据 → 各项费用计算 → 单位工程概算书编制 → 单项工程综合概算书的编制 → 建设项目总概算的编制（自下而上逐级汇总）

15.1.4 设计概算编制方法★★★★★2016~2025连年考▶

1. 设计概算编制形式 2024多选

二级形式当只有一个单项工程的建设项目时，应采用二级形式编制设计概算
三级形式当包含两个及以上单项工程的建设项目时，应采用三级编制形式。"三级概算"是指单位工程概算、单项工程综合概算和建设工程项目总概算
⚠ 一个单项工程→二级；两个及以上→三级。"三级概算"三个层次的名称（单位→单项→总）常考多选，注意与施工图预算"三级预算"（单位工程预算→单项工程综合预算→建设项目总预算）对应区分。

2. 设计概算文件的组成内容 2016·2020单选

建设工程项目总概算由 ①单项工程综合概算 ②工程建设其他费用概算 ③预备费概算 ④建设期利息概算 ⑤经营性项目铺底流动资金概算 组成
单位建筑工程概算土建工程概算、给水排水采暖工程概算、通风空调工程概算、电气照明工程概算、弱电工程概算、特殊构筑物工程概算
单位设备及安装工程概算机械设备及安装工程概算、电气设备及安装工程概算、热力设备及安装工程概算、工器具及生产家具购置费概算

3. 单位工程概算的编制方法 2016·2018~2025单选

方法适用条件要点
概算定额法 初步设计达到一定深度、建筑结构比较明确（可以计算工程量） 五步：①按概算定额分部分项顺序列出各分项工程名称 ②确定概算定额单价（基价）③计算人、材、机费用 ④分别计算企业管理费、利润、规费和税金 ⑤计算单位工程概算造价
概算指标法 在初步设计、方案设计或概念性设计深度不够，工程量无法准确提供或计算，行业和地方对应概算定额资料不足，而工程设计采用的技术比较成熟，已有平台数据库存有建设地点、工程特征和结构特征、建设规模等类似概算指标时采用。适用于一般附属、辅助和服务工程等项目，以及住宅和文化福利工程项目或投资比较小、比较简单的工程项目 结构特征与指标相同或相近→直接套用；有局部差异→修正指标（两种：修正每m²造价 / 修正人、材、机数量）
类似工程预算法 拟建工程初步设计与已完工程或在建工程的设计相类似且没有可用的概算指标 但必须对建筑结构差异和价差进行调整
单位工程概算造价 = 人、材、机费用 + 企业管理费 + 利润 + 规费 + 税金 结构变化修正概算指标(元/m²) = 原概算指标人材机费 + 换入结构的工程量×换入结构的人材机费用单价 − 换出结构的工程量×换出结构的人材机费用单价 结构变化修正概算指标的人、材、机数量 = 原概算指标人材机数量 + 换入结构件工程量×相应定额人材机消耗量 − 换出结构件工程量×相应定额人材机消耗量
⚠ 三法辨析：结构明确、可算工程量→概算定额法；设计深度不够、有类似指标库→概算指标法；与已完/在建工程类似且无可用概算指标→类似工程预算法（须调结构差异+价差）。
【2024真题】初步设计达到一定深度、建筑结构比较明确，可以计算工程量的建筑工程，编制设计概算宜采用（ ）
答案 B：概算定额法。
【2025真题】按概算指标编制概算：土建含税单位造价1627元/m²（人材机1230元/m²），企业管理费率8%（以人材机为基数），利润率7%（以人材机+管理费为基数），结构构件部分变更使每100m²人材机费用增加4800元，增值税率9%，修正后含税单位造价为（ ）元/m²
答案 B：1687.46。修正后含税单位造价 = 1627 + (4800÷100)×(1+8%)×(1+7%)×(1+9%) = 1687.46 元/m²。

4. 设备及安装工程概算编制方法 2016单选 2018~2023多选

方法适用条件 / 要点
预算单价法当初步设计有详细设备清单时，可直接按预算单价（预算定额单价）编制。计算比较具体，精确性较高
扩大单价法初步设计的设备清单不完备，或仅有成套设备的重量时，可采用综合扩大安装单价编制
概算指标法当初步设计的设备清单不完备，或安装预算单价及扩大综合单价不全，无法采用前两法时。概算指标形式：
① 按设备价值的百分比（安装费率）：设备安装费=设备原价×设备安装费率
② 按每吨设备安装费：设备安装费=设备总吨数×每吨设备安装费(元/吨)
③ 按座、台、套、组、根或功率等为计量单位
④ 按设备安装工程每平方米建筑面积
【例题】初步设计深度不够、设备清单不完善，只有主体设备或仅有成套设备重量时，编制设备安装工程概算应选用（ ）
答案 B：扩大单价法。

5. 建设工程项目总概算的编制方法 2024多选·2026修订

  • 以整个建设工程项目为对象，是确定项目从筹建开始到竣工验收交付使用整个过程全部费用（即建设项目总投资）的文件
  • 由工程费用、工程建设其他费用、预备费、建设期利息和经营性项目的铺底流动资金组成
  • 按概算编制工作顺序由各单项工程综合概算、工程建设其他费用、预备费、建设期利息和经营性项目的铺底流动资金组成
  • 总概算表编制步骤：①单项工程综合概算及其他工程和费用概算汇总列入总概算表 ②工程项目和费用名称及数值填入相应各栏 ③按费率标准计算预备费、建设期利息、铺底流动资金 ④计算总概算价值 ⑤计算技术经济指标 ⑥投资分析
总概算价值 = 工程费用 + 工程建设其他费用 + 预备费 + 建设期利息 + 铺底流动资金
【例题】某项目工程费用6500万、其他费用1200万、预备费500万、建设期贷款利息370万、铺底流动资金700万，总概算为（ ）万元
答案 A：9270。6500+1200+500+370+700=9270 万元（五项全加，一项不落）。
15.1.5 设计概算编制成果文件★★★▶

设计概算成果文件——设计概算书（也简称设计概算或总概算书），一般应包括七个部分：

  • (1) 封面、签署页及目录　(2) 编制说明　(3) 总概算表　(4) 工程建设其他费用概算表　(5) 单项工程综合概算表　(6) 单位工程概算表　(7) 附录：补充估价表
15.2 施工图预算编制▶
15.2.1 施工图预算定义和作用★★★2018·2020·2023多选▶
对建设单位① 施工图设计阶段确定建设工程项目投资的依据；② 施工期间安排建设资金计划和使用建设资金的依据；③ 确定项目最高投标限价的参考依据；④ 可以作为确定合同价款、拨付工程进度款及办理工程结算的基础
对施工单位① 确定投标报价的参考依据；② 进行施工准备的依据；③ 施工前组织材料、机具、设备及劳动力供应的重要参考；④ 编制进度计划、统计完成工作量、进行经济核算的参考依据；⑤ 控制工程成本的依据；⑥ 进行"两算"对比的依据（"两算"指施工图预算和施工预算）
对工程咨询单位尽可能客观、准确地为委托方做出施工图预算，是其业务水平、素质和信誉的体现
对造价管理部门① 监督检查执行国家及行业标准的依据；② 合理确定工程造价、测算造价指数的依据；③ 审核最高投标限价的参考依据
其他是有关仲裁、管理、司法机关按照法律程序处理、解决问题的依据
⚠ "两算"对比 = 施工图预算 与 施工预算（施工单位内部），不是"概算与预算"——多选常设此坑。另注意：确定最高投标限价对建设单位是"参考依据"，审核最高投标限价对造价管理部门也是"参考依据"。
15.2.2 施工图预算编制依据★★★▶
  • 国家、行业和地方有关规定
  • 预算定额或企业定额、单位估价表等
  • 施工图设计文件及相关标准图集和规范
  • 项目相关文件、合同、协议等
  • 工程所在地的人工、材料、设备、施工机具单价，工程造价指标指数等
  • 施工组织设计和施工方案
  • 项目的管理模式、发包模式及施工条件
  • 其他应提供的资料
⚠ 对比记忆：概算依据用概算定额（指标）+勘察设计文件；施工图预算依据用预算定额/企业定额+施工图设计文件——两套依据别混。
15.2.3 施工图预算的编制工作程序★★★▶

单位工程预算 → 单项工程综合预算 → 建设项目总预算（逐级汇总）

15.2.4 施工图预算编制方法★★★★★2017~2025高频单选▶

1. 定额单价法 2017·2019·2020·2022·2024·2025单选

七步程序① 准备资料，熟悉施工图纸 → ② 计算工程量 → ③ 套用定额单价，计算人、材、机费用 → ④ 编制工料分析表 → ⑤ 按计价程序计取其他费用，并汇总造价 → ⑥ 复核 → ⑦ 编制说明、填写封面
套用定额单价注意 (1) 名称、规格、计量单位与定额单价中所列内容完全一致时，可以直接套用定额单价；
(2) 主要材料品种与定额单价中规定材料不一致时，不可以直接套用定额单价，需要按实际使用材料价格换算定额单价；
(3) 施工工艺条件与定额单价不一致而造成人工、机械的数量增减时，一般调量不换价；
(4) 不能直接套用定额、不能换算和调整时，应编制补充定额单价
⚠ 助记口诀：完全一致，直接套用；材料不一致，价格换算；数量增减，调量不换价。选项常把"换价"与"换量"互换设坑。
【2025真题】定额单价法编制施工图预算，完成工程量计算后下一步应进行的工作是（ ）
答案 D：套用定额单价，计算人、材、机费用。（顺序：工程量→套价算人材机→工料分析表→计取其他费用汇总→复核→说明封面）
【2024真题】套用定额单价计算人材机费用时，某分项工程主要材料品种与定额单价中规定材料不一致，处理方式是（ ）
答案 B：按实际使用材料价格换算定额单价。

2. 实物量法 2018·2019·2022·2023单选

七步程序① 准备资料，熟悉施工图纸 → ② 计算工程量 → ③ 套用消耗定额，计算人、材、机消耗量 → ④ 计算并汇总人工费、材料费、施工机具使用费 → ⑤ 计算其他各项费用，汇总造价 → ⑥ 复核 → ⑦ 编制说明、填写封面
⚠ 两法第③④步区别：定额单价法③套定额单价直接算出人材机费用；实物量法③套消耗定额先算人材机消耗量、④再乘市场价格汇总费用。
【2024真题】实物量法编制施工图预算工作排序：①计算工程量 ②套用消耗定额计算人材机消耗量 ③计算其他各项费用并汇总造价 ④计算并汇总人材机费用 ⑤准备资料、熟悉施工图纸
答案 D：⑤—①—②—④—③。
15.2.5 施工图预算编制成果文件★★★▶
三级预算编制多个单项工程时：建设项目总预算、单项工程综合预算、单位工程预算。成果文件组成：(1)封面 (2)签署页及目录 (3)编制说明 (4)总预算表 (5)综合预算表 (6)单位工程预算表 (7)附件
二级预算编制一个单项工程时：(1)封面 (2)签署页及目录 (3)编制说明 (4)总预算表 (5)单位工程预算表 (6)附件（无综合预算表）
15.3 设计概算与施工图预算的审查▶
15.3.1 设计概算与施工图预算审查的意义★★★▶
  • 有助于促进编制人员提高编制质量
  • 有助于促进设计的技术先进性与经济合理性的统一
  • 可以使建设项目总投资力求做到准确、完整，缩小概算与预算之间的差距，避免实际投资大幅突破概算
  • 有利于核定建设项目的投资规模
  • 有利于合理分配投资资金、加强投资计划管理
15.3.2 内部审核和外部审查或评审★★★▶
内部审核编制、审核、审定——编制的项目负责人是第一责任人
外部审查或评审第三方审核。内容包括：项目建设程序评审、建筑安装工程概算评审、设备投资概算评审、待摊投资概算评审、其他投资概算评审
15.3.3 设计概算的审查内容★★★2025多选▶

1. 审查设计概算的编制依据：(1)定额和标准的时效性 (2)针对性 (3)合理性 (4)对影响造价或投资水平的主要因素或关键工程的必要说明 (5)适用性

2. 审查单位工程设计概算构成 2025多选

  • 审查建筑工程概算，包括对工程量计算、概算定额选用、取费及材料价格等的审查
  • 采用的定额或指标的审查：审查定额或指标的使用范围、定额基价、指标的调整、定额或指标缺项的补充等
  • 材料预算价格的审查
  • 各项费用的审查

3. 设备及安装工程概算的审查（表15-4）

标准设备原价应根据设备被管辖的范围，审查各级规定的价格标准
非标准设备原价除审查价格的估算依据、估算方法外，还要分析研究非标准设备估价准确度的有关因素及价格变动规律
设备运杂费费率按主管部门或省、自治区、直辖市规定的标准执行；若设备价格中已包括包装费和供销部门手续费，不应重复计算，应相应降低设备运杂费率
进口设备费用应根据设备费用各组成部分及国家设备进口、外汇管理、海关、税务等有关部门不同时期的规定进行
其他采用预算单价或扩大综合单价计算安装费时，审查各种单价是否合适、工程量计算是否符合规则要求、是否准确无误；采用概算指标计算安装费时，审查概算指标是否合理、计算结果是否达到精度要求；审查所需计算安装费的设备数量及种类是否符合设计要求，避免将不需安装的设备安装费计入

4. 综合概算和总概算的审查

  • 审查概算的编制是否符合国家经济建设方针、政策的要求，是否实事求是地确定项目总投资
  • 工程建设其他费概算的审查
  • 审查概算的投资规模、生产能力、设计标准、建设用地、建筑面积、主要设备、配套工程、设计定员等是否符合原批准可行性研究报告或立项批文的标准
  • 审查其他具体项目：技术经济指标是否经济合理、费用项目是否按统一规定计列，有无随意列项、多列、交叉计列和漏项等
⚠ 如概算总投资超过原批准投资估算 10% 以上，应进一步审查超估算的原因——"10%"是高频数字考点。

15.3.5 施工图预算的审查内容★★★▶

重点：对工程量、资源要素价格、预算单价的套用、费率及计取等进行审核。

主要内容：

  • 审查施工图预算的编制是否符合现行国家、行业、地方政府有关法律、法规和规定要求
  • 审查工程量计算的准确性、工程量计算规则与计量标准或定额规则的一致性
  • 审查在施工图预算的编制过程中，各种计价依据使用是否恰当，各项费率计取是否正确
  • 审查各种要素市场价格选用是否合理
  • 审查施工图预算是否超过设计概算以及进行偏差分析

审查方法特点适用范围
逐项审查法
（全面审查法）		优点：全面、细致，审查质量高、效果好；缺点：工作量大，时间较长工程量较小、工艺比较简单的工程
标准预算审查法优点：时间短、效果好、易定案；缺点：适用范围小仅适用于采用标准图纸的工程
分组计算审查法审查速度快、工作量小—
对比审查法—①拟建工程与已完或在建工程预算采用同一施工图，但基础部分和现场施工条件不同→相同部分对比审查；②工程设计相同但建筑面积不同→按分项工程量比例或每m²建筑面积造价对比；③两工程面积相同但设计图纸不完全相同→相同部分（柱子、屋架、屋面、砖墙等）对照审查
"筛选"审查法优点：简单易懂，便于掌握，审查速度快，便于发现问题；缺点：问题出现的原因尚需继续审查审查住宅工程或不具备全面审查条件的工程
重点审查法突出重点，审查时间短、效果好审查工程量大或者造价较高的各种工程、补充定额、计取的各种费用（计费基础、取费标准）等
⚠ 适用范围最易混：工程量小、工艺简单→逐项(全面)审查；标准图纸→标准预算审查；住宅/不具备全面审查条件→"筛选"审查；工程量大、造价高→重点审查。特点关键词："全面细致质量高"=逐项；"易定案范围小"=标准；"速度快工作量小"=分组；"简单易懂便于发现问题"=筛选。
【2024真题】施工图预算审查时，对工程量小、工艺较简单的工程，按定额顺序或施工顺序对各项工程细目逐项详细审查的方法属于（ ）
答案 B：全面审查法（逐项审查法）。
