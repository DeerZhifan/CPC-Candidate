第一篇 · 工程经济

1资金时间价值（六大等值公式）

全书计算地基。核心是"现金流在不同时间点按利率 i 等值换算"，一切评价指标都建立在此之上。

六个等值换算公式

① 一次支付终值（整存整取）
F = P(1+i)n
P现值 · F终值 · i利率 · n期数；系数 (F/P,i,n)=(1+i)n
已知现在P，求将来F
② 一次支付现值
P = F(1+i)−n
系数 (P/F,i,n)=(1+i)−n，即①的倒数（贴现）
已知将来F，求现在应投P
③ 等额支付终值（零存整取）
F = A·[(1+i)n−1]/i
A=每期期末等额支付；系数 (F/A,i,n)
已知每年存A，求n年末总额F
④ 偿债基金（为攒F每年存多少）
A = F·i/[(1+i)n−1]
系数 (A/F,i,n)，即③的倒数
已知目标F，求每年应存A
⑤ 等额支付现值
P = A·[(1+i)n−1]/[i(1+i)n]
系数 (P/A,i,n)（年金现值系数，最常用）
已知每年收益A，求现在总值P
⑥ 资本回收（投P每年能回收多少）
A = P·i(1+i)n/[(1+i)n−1]
系数 (A/P,i,n)，即⑤的倒数
已知投资P，求每年等额回收A（NAV法基础）
💡 互为倒数关系：①↔② · ③↔④ · ⑤↔⑥。记住"终值系数×现值系数=1"，考试给一个可推另一个。口诀"整存整取、零存整取、偿债基金、资本回收"。

名义利率与有效利率

有效（实际）年利率
i = (1 + r/m)m − 1
r名义年利率 · m一年计息次数
计息周期<1年（月/季计息）时换算
⚠ 名义利率 r 直接可加、可拆（月利率×12=名义年利率）；有效利率随计息频次升高而变大。当 m=1 时二者相等；m→∞ 趋于 er−1。题目问"实际/有效"必须换算。
经典例题 1-A终值/现值
某项目现投资 1000 万元，年利率 10%，按复利计，3 年末可积累多少？又：若希望未来 5 年内每年末各获得 300 万元，年利率 10%，现在应一次投入多少？
解： ① 终值 F = 1000×(1+0.10)³ = 1000×1.331 = 1331 万元 ② 年金现值 P = 300×(P/A,10%,5) = 300×3.7908 = 1137.24 万元 〔(P/A,10%,5) = (1.1⁵−1)/(0.1×1.1⁵) = 0.61051/0.161051 = 3.7908〕
答：3 年末积累 1331 万元；需一次投入约 1137.24 万元。
经典例题 1-B有效利率
名义年利率 12%，若按月计息，实际年利率是多少？
解： m=12，月利率 = 12%/12 = 1% i = (1+0.01)¹² − 1 = 1.1268 − 1 = 12.68%
答：有效年利率 12.68% > 名义 12%。

2经济效果评价指标

判断方案"值不值得干"。分静态（不考虑资金时间价值）与动态（考虑）两类，动态更常考。

净现值 NPV
NPV = Σ(CI−CO)t(1+ic)−t
CI现金流入 · CO流出 · ic基准收益率
判据 NPV≥0 可行；越大越优
净年值 NAV
NAV = NPV·(A/P,ic,n)
把 NPV 摊成等额年值
判据 NAV≥0；寿命不同的方案比选用 NAV
内部收益率 IRR（内插近似）
IRR ≈ i₁ + (i₂−i₁)·NPV₁/(NPV₁−NPV₂)
令 NPV=0 的折现率；i₁使NPV₁>0，i₂使NPV₂<0
判据 IRR≥ic 可行
静态投资回收期 Pt
Pt = (累计净现金流出现正值的年数−1) + 上年绝对值/当年净现金流
从建设开始算起，不折现
判据 Pt≤基准回收期；越短越好
动态投资回收期 P′t
P′t = (累计折现净现金流出现正值的年数−1) + 上年累计折现值绝对值/当年折现净现金流
净现金流先按 ic 折现再累计
判据 P′t≤基准；恒有 P′t>Pt
效益费用比 RBC
R = PV(效益) / PV(费用)
均折现到基准年
判据 R≥1 可行
差额投资内部收益率 ΔIRR（互斥方案）
令 Σ(ΔCI−ΔCO)t(1+ΔIRR)−t = 0
用"投资大−投资小"两方案的差额现金流求 IRR
判据 ΔIRR≥ic 选投资大者，否则选投资小者
⚠ ①寿命期不同的互斥方案不能直接比 NPV，要用 NAV（或最小公倍数法）。②IRR 内插只是近似，i₁、i₂ 间隔越小越准（一般≤2%~5%）。③NPV>0 ⇔ IRR>ic ⇔ R>1，三者判断方向一致。④投资额不同的互斥方案不能只看各自 IRR 大小，须用 ΔIRR 或 NPV 判优（IRR 高的方案 NPV 未必大）。
经典例题 2-ANPV
某项目第 0 年初投资 1000 万元，第 1~5 年每年末净收益 300 万元，基准收益率 ic=10%。求 NPV 并判断可行性。
解： NPV = −1000 + 300×(P/A,10%,5) = −1000 + 300×3.7908 = −1000 + 1137.24 = +137.24 万元 > 0
答：NPV=137.24 万元>0，方案在经济上可行。
经典例题 2-BIRR 内插
已算得折现率 12% 时 NPV₁=+50 万元，15% 时 NPV₂=−30 万元。求内部收益率 IRR。
解： IRR ≈ 12% + (15%−12%)×50/[50−(−30)] = 12% + 3%×50/80 = 12% + 1.875% = 13.88%
答：IRR≈13.88%；若>基准收益率则可行。

3不确定性分析

回答"抗风险能力如何"。三大工具：盈亏平衡（临界产量）、敏感性（哪个因素最敏感）、概率分析。

盈亏平衡产量（BEP）
Q* = CF / (p − cv − t)
CF年固定成本 · p单价 · cv单位变动成本 · t单位税金
产量>Q* 才盈利；Q* 越低抗风险越强
生产能力利用率 BEP
E* = Q* / Q设计 ×100%
用设计生产能力表示的盈亏平衡点
E* 越小越安全
敏感度系数
SAF = (ΔA/A) / (ΔF/F)
评价指标变化率 ÷ 不确定因素变化率
|S| 越大越敏感；>1 为敏感因素
概率分析·期望值
E(NPV) = Σ Pi · NPVi
Pi各状态发生概率（ΣPi=1）· NPVi该状态下净现值
E(NPV)>0 可行；配合 NPV≥0 的累计概率判风险
⚠ 盈亏平衡分析属确定性因素下的临界点分析，只用于单一项目抗风险判断，不能用于多方案比选。敏感度系数取绝对值排序。
经典例题 3-A盈亏平衡
某产品年固定成本 100 万元，单价 100 元，单位变动成本 60 元，单位税金 0；设计年产能 5 万件。求盈亏平衡产量与生产能力利用率。
解： Q* = 1 000 000 / (100−60−0) = 1 000 000 / 40 = 25 000 件 E* = 25 000 / 50 000 ×100% = 50%
答：年产 2.5 万件保本；产能利用率达 50% 即盈亏平衡。

4设备更新分析

核心是求"经济寿命"——年平均使用成本最低的年限；以及新旧设备、租赁与购买的比选。

经济寿命（低劣化数值法·静态）
N₀ = √(2(P−L)/λ)
P设备原值 · L最终残值 · λ年运行成本逐年递增额（低劣化值）
使年平均总成本最低的使用年限
年平均使用成本（列表法·静态）
AC(n)=[(P−Ln)+ΣCt]/n
逐年试算、不折现，取 AC 最小的 n
残值/运营费不规则时求经济寿命
费用年值法 AC（动态·方案比选）
AC = P·(A/P,i,n) + C − L·(A/F,i,n)
P投资（旧设备取市场转让价）· C年运行成本 · L期末残值 · 三项：资本回收费＋年运行费−残值年回收
判据 AC 最低者优；寿命不同的方案可直接比
💡 设备更新比选只比未来成本，旧设备原始购价属"沉没成本"不计入；旧设备的"现值"应按市场变现价值作为继续使用的机会成本。费用年值法把寿命不等的方案都摊成"等额年成本"，故可直接比较——这正是它优于现值法之处。
经典例题 4-A经济寿命
某设备原值 10 000 元，最终残值近似为 0，年运行成本逐年递增额 λ=500 元。用低劣化数值法估算经济寿命。
解： N₀ = √(2×(10 000−0)/500) = √40 ≈ 6.3 年
答：经济寿命约 6 年（取整）。
经典例题 4-B费用年值法·新旧比选
旧设备 A 现市场转让价 90 万元，尚可用 6 年，年运行成本 80 万元，6 年末残值 25 万元；新设备 B 购价 300 万元，可用 10 年，年运行成本 50 万元，10 年末残值 35 万元。i=10%。系数 (A/P,10%,6)=0.2296、(A/F,10%,6)=0.1296、(A/P,10%,10)=0.1627、(A/F,10%,10)=0.0627。用费用年值法比选。
解：（旧设备投资取市场转让价 90，寿命 6 年；不算原始购价） ACA = 90×0.2296 + 80 − 25×0.1296 = 20.66 + 80 − 3.24 = 97.42 万元 ACB = 300×0.1627 + 50 − 35×0.0627 = 48.81 + 50 − 2.19 = 96.62 万元 ACA(97.42) > ACB(96.62)
答：ACB 更低，购买新设备 B 的方案较优。

5价值工程

用最低寿命周期成本可靠实现必要功能。核心指标价值 = 功能 ÷ 成本。

价值 V
V = F / C
F功能 · C寿命周期成本
V=1 理想；V<1 成本偏高（重点改进对象）；V>1 功能过剩或成本偏低
价值指数（对象选择）
Vi = Fi / Ci
功能系数 Fi=功能评分/Σ评分；成本系数 Ci=部件成本/总成本
Vi 最小、成本-功能差(Ci−Fi)最大者为改进重点
⚠ 提高价值的5 条途径：功能↑成本↓（最优）｜功能不变成本↓｜功能↑成本不变｜功能略降成本大降｜成本略增功能大增。单纯降低功能不是提高价值的途径。
经典例题 5-A对象选择
某产品甲、乙、丙三部件，功能评分 40/35/25，成本占比 30%/45%/25%。哪个是价值工程改进重点？
解：功能系数 F = 0.40/0.35/0.25；成本系数 C = 0.30/0.45/0.25 V甲=0.40/0.30=1.33；V乙=0.35/0.45=0.78；V丙=0.25/0.25=1.00
答：乙 V 最小(0.78)、成本-功能差最大，是改进重点。

6财务分析比率

从财务报表看企业/项目的偿债、营运、盈利三方面能力，均为"比值"，记牢分子分母。

类别指标计算式说明
偿债能力资产负债率负债总额 / 资产总额越低偿债越有保障
流动比率流动资产 / 流动负债一般 ≥2
速动比率(流动资产−存货) / 流动负债一般 ≥1
利息备付率息税前利润EBIT / 应付利息≥1，宜>2
偿债备付率(EBITDA−所得税) / 应还本付息额≥1，宜>1.3
营运能力应收账款周转率营业收入 / 平均应收账款次/年，越高越好
存货周转率营业成本 / 平均存货越高营运效率越好
总资产周转率营业收入 / 平均资产总额反映全部资产利用率
盈利能力总资产报酬率息税前利润EBIT / 平均资产总额不受资本结构影响
净资产收益率净利润 / 平均净资产股东回报核心指标
资本金净利润率净利润 / 资本金投资者关注
⚠ 分子口径易错：存货周转率用"营业成本"作分子，应收账款周转率用"营业收入"作分子。利息备付率分子是 EBIT（息税前），偿债备付率分子是 EBITDA 减所得税。
经典例题 6-A偿债比率
某企业流动资产 800 万元（其中存货 300 万元），流动负债 400 万元。求流动比率与速动比率。
解： 流动比率 = 800/400 = 2.0（达标） 速动比率 = (800−300)/400 = 500/400 = 1.25（达标）
答：流动比率 2.0、速动比率 1.25，短期偿债能力良好。

7资金成本与加权平均资金成本

筹资的"价格"。个别资金成本取税后口径，再按占比加权得 WACC，用于判断筹资方案与作折现率参考。

个别资金成本（税后）
K = [年资金占用费×(1−T)] / [筹资额×(1−f)]
T所得税率 · f筹资费率；借款/债券利息可抵税（乘 1−T），股权资金成本不抵税
分别算借款、债券、优先股、普通股、留存收益成本
加权平均资金成本 WACC
Kw = Σ(Wj · Kj)
Wj第 j 种资金占筹资总额比重 · Kj其个别资金成本
综合筹资成本，越低越优
💡 只有债务性资金（借款、债券）的利息能抵税，故税后成本更低——这是适度负债能降低综合资金成本的原因。留存收益成本≈普通股成本但无筹资费。
经典例题 7-AWACC
某项目资金结构：银行借款占 40%、税后成本 6%；权益资金占 60%、成本 10%。求加权平均资金成本。
解： Kw = 40%×6% + 60%×10% = 2.4% + 6.0% = 8.4%
答：加权平均资金成本 8.4%。

8营运资金管理

管好现金、应收账款、存货。计算重点是存货的经济订货批量 EOQ 与最佳现金持有量。

经济订货批量 EOQ
Q* = √(2·D·S / H)
D年需求量 · S每次订货成本 · H单位年储存成本
使"订货成本+储存成本"之和最小
最佳现金持有量（成本分析模型）
min 相关总成本 = 机会成本 + 管理成本 + 短缺成本
机会成本=持有现金放弃的投资收益，随持有量↑而↑ · 管理成本=固定成本，与持有量基本无关 · 短缺成本=现金不足造成的损失，随持有量↑而↓
列表试算各方案，三项之和最小者为最佳持有量
⚠ 成本分析模型用机会成本+管理成本+短缺成本三项（管理成本是固定成本，不影响最优点位置，故最优点实为"机会成本+短缺成本"最小处）；存货模型（鲍莫尔）则只权衡持有机会成本与交易/转换成本，用 C*=√(2·T·F/K)。两模型的成本项别混。
经典例题 8-AEOQ
某材料年需求量 3600 吨，每次订货成本 25 元，每吨每年储存成本 2 元。求经济订货批量。
解： Q* = √(2×3600×25 / 2) = √90 000 = 300 吨 全年订货次数 = 3600/300 = 12 次
答：每次订购 300 吨最经济，全年订 12 次。

9固定资产折旧计算

折旧把固定资产原值在使用年限内分摊进成本。直线法最基础；加速折旧（双倍余额递减、年数总和）前期多提、后期少提，是高频计算与易错点。

① 年限平均法（直线法）
年折旧额 = (原值 − 预计净残值)/折旧年限
年折旧率 = (1 − 净残值率)/折旧年限；每年折旧额相等
最常用；残值率一般取 3%~5%
② 工作量法
某期折旧 = 该期工作量 × (原值−净残值)/预计总工作量
单位工作量折旧额固定，按实际工作量提取
运输设备、大型施工机械（按台班/里程）
③ 双倍余额递减法（加速）
年折旧额 = 期初账面净值 × 2/折旧年限
折旧率 2/n 不扣残值；最后两年改直线法，把剩余净值减残值后均摊
前期折旧多、抵税早
④ 年数总和法（加速）
年折旧额 = (原值−净残值) × 尚可使用年数/年数总和
年数总和 = n(n+1)/2；折旧率逐年递减，一开始就扣净残值
前期折旧多、抵税早
💡 三种方法累计折旧总额相同（都等于"原值−净残值"），只是年度分摊节奏不同。加速折旧前期多提折旧→前期利润小、所得税少，等于把纳税时间后移，获得资金时间价值上的合法节税收益。
⚠ 双倍余额递减法算折旧率时不减净残值（率=2/n），但最后两年务必改直线法把剩余净值（扣除残值后）均分，否则会把残值也提完；年数总和法则从第一年起分子就用"原值−净残值"。两法方向别记反。

经典例题 9-A加速折旧
某设备原值 100 万元，预计净残值 4 万元，使用年限 5 年。分别用双倍余额递减法和年数总和法计算各年折旧额。
解：双倍余额递减法（率 = 2/5 = 40%，前 3 年按期初净值提取） 第 1 年 = 100×40% = 40；第 2 年 =(100−40)×40% = 24；第 3 年 =(60−24)×40% = 14.4 末两年改直线：期初净值 = 36−14.4 = 21.6，扣残值 4 后 17.6 均分 → 第 4、5 年各 8.8 校核：40+24+14.4+8.8+8.8 = 96 = 100−4 ✓ 解：年数总和法（年数总和 = 5×6/2 = 15，可提折旧 = 100−4 = 96） 第 1 年 = 96×5/15 = 32；第 2 年 = 96×4/15 = 25.6；第 3 年 = 96×3/15 = 19.2；第 4 年 = 96×2/15 = 12.8；第 5 年 = 96×1/15 = 6.4
答：见上方对比表；两种加速法五年累计折旧均为 96 万元，仅分摊节奏不同。

10收入 · 利润 · 所得税计算

建造合同收入按履约进度（完工百分比）确认；再由营业利润推出利润总额、净利润与应纳所得税。

履约进度（完工百分比）
进度 = 累计实际合同成本 / 合同预计总成本 ×100%
或按工作量法 = 累计已完工程量 / 预计总工程量 ×100%
分母是预计总量，设计变更后须更新
当期确认的合同收入
当期收入 = 合同总收入 × 完工进度 − 以前期间累计已确认收入
先算"累计应确认"，再减以前累计，得本期
累计法，非当年增量直接×进度
利润总额与净利润
利润总额 = 营业利润 + 营业外收入 − 营业外支出；净利润 = 利润总额 − 所得税费用
营业利润 = 营业收入 − 营业成本 − 税金及附加 − 期间费用 ∓ 各类损益
利润表自上而下逐层结出
应纳所得税额
应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额
应纳税所得额 = 利润总额 ± 纳税调整，未必等于利润总额；企业所得税率一般 25%
先纳税调整、再乘税率
⚠ ①完工进度分母用预计总成本/总工程量，设计变更后分母要相应调整；②当期收入用累计法（总收入×累计进度 − 以前累计），不是"当年增量×进度"；③应纳税所得额 ≠ 利润总额，需纳税调整后再乘税率。
经典例题 10-A完工百分比·收入
某建造合同总收入 5000 万元。第 1 年末累计履约进度 30%，第 2 年末累计履约进度 80%。求第 2 年应确认的合同收入。
解：累计法 第 2 年收入 = 5000×80% − 5000×30% = 4000 − 1500 = 2500 万元
答：第 2 年确认合同收入 2500 万元。
经典例题 10-B利润·所得税
某企业营业利润 800 万元，营业外收入 50 万元，营业外支出 30 万元，所得税税率 25%（暂不考虑纳税调整）。求利润总额、应纳所得税额与净利润。
解： 利润总额 = 800 + 50 − 30 = 820 万元 应纳所得税 = 820×25% = 205 万元（此处按应纳税所得额=利润总额简化） 净利润 = 820 − 205 = 615 万元
答：利润总额 820 万、所得税 205 万、净利润 615 万元。
第三篇 · 工程计价

11建设项目总投资构成及计算

"造价一张树"：总投资=建设投资+建设期利息+流动资金。计算高频点是预备费与建设期利息。

层次构成
建设投资工程费用（建筑安装工程费＋设备及工器具购置费）＋工程建设其他费＋预备费
预备费基本预备费（应对一般变更）＋价差预备费（应对涨价）
总投资建设投资 ＋ 建设期利息 ＋ 流动资金（生产性项目）
基本预备费
基本预备费 = (工程费用 + 工程建设其他费) × 费率
费率按行业规定
应对设计变更、一般自然灾害等
价差预备费
PF = Σ It[(1+f)m(1+f)0.5(1+f)t−1 − 1]
It第 t 年投资 · f年涨价率 · m建设前期年限；投资当年按半年（0.5）计
应对建设期物价上涨
建设期利息（当年借款半年计息）
qj = (Pj−1 + Aj/2) × i
Pj−1年初借款本息累计 · Aj当年借款 · i年利率
当年新增借款按年中支用、计半年利息
经典例题 11-A建设期利息
建设期 2 年，第 1 年借款 500 万元、第 2 年借款 300 万元，年利率 6%，借款均在年中支用。求建设期利息合计。
解： 第 1 年 q₁ = (0 + 500/2)×6% = 250×6% = 15 万元 第 2 年 q₂ = (500+15 + 300/2)×6% = (515+150)×6% = 665×6% = 39.9 万元 合计 = 15 + 39.9 = 54.9 万元
答：建设期利息合计 54.9 万元（注意第 2 年要含第 1 年利息滚入本金）。
经典例题 11-B基本预备费
某项目工程费用 8000 万元，工程建设其他费 1000 万元，基本预备费率 5%。求基本预备费。
解： 基本预备费 = (8000 + 1000)×5% = 9000×5% = 450 万元
答：基本预备费 450 万元（不含价差预备费作基数）。

12工程造价构成、设备购置费与取费

工程费用往下拆：设备购置费（含进口设备抵岸价）、建安费两种划分与取费基数、增值税，静态/动态投资口径，以及设计概算指标的结构变化修正。

设备购置费
设备购置费 = 设备原价(或进口抵岸价) + 设备运杂费
设备运杂费 = 设备原价(或抵岸价) × 运杂费率
属工程费用中的"设备及工器具购置费"
进口设备抵岸价
抵岸价 = 货价 + 国外运费 + 国外运输保险费 + 银行财务费 + 外贸手续费 + 进口关税 + 增值税 + 消费税
关税 = 到岸价CIF×汇率 × 关税率；组成计税价 = CIF×汇率 + 关税 + 消费税；进口增值税 = 组成计税价 × 税率
进口设备原价的完整构成
建安费两种划分
要素法 = 人工+材料+施工机具使用费+企业管理费+利润+规费+税金
造价形成 = 分部分项费+措施项目费+其他项目费+规费+税金
两种口径金额相等，只是归集方式不同
措施项目费 = Σ(措施工程量×综合单价)
取费基数与增值税
企业管理费 / 利润 = 取费基数 × 费率；税金 = 税前造价 × 9%
取费基数视定额规定取"人工费""人工费+机械费"或"人材机费"；建筑业销项增值税率 9%
基数口径不同结果差异大，须按题目定额
静态 / 动态投资
静态投资 = 工程费用 + 工程建设其他费 + 基本预备费；动态投资 = 价差预备费 + 建设期利息
基本预备费属静态；价差预备费、建设期利息属动态
静态/动态基数区分是本篇第一大坑
设计概算·结构变化修正（概算指标法）
修正指标 = 原概算指标 + 换入结构工程量×换入单价 − 换出结构工程量×换出单价
套用类似工程概算指标、仅个别结构不同时用；人材机数量同理逐项换算
先"减换出、加换入"再得修正后单方造价
⚠ ①进口设备关税以到岸价(CIF)为基数，而进口增值税以"组成计税价格"（CIF+关税+消费税）为基数，两者基数不同；②基本预备费算静态、价差预备费算动态，别归错；③管理费/利润的取费基数以题目定额为准，人工费基数与人材机基数结果差别很大。
经典例题 12-A进口设备·关税增值税
某进口设备到岸价(CIF)折人民币 1000 万元，进口关税税率 8%，进口环节增值税率 13%，消费税为 0。求进口关税、进口增值税及税金合计。
解： 进口关税 = 1000×8% = 80 万元 组成计税价格 = 1000 + 80 + 0 = 1080 万元 进口增值税 = 1080×13% = 140.4 万元；税金合计 = 80 + 140.4 = 220.4 万元
答：关税 80 万、增值税 140.4 万，税金合计 220.4 万元（增值税基数是组成计税价格 1080，不是 CIF 1000）。
经典例题 12-B概算指标·结构变化修正
拟建工程套用类似工程概算指标 1200 元/m²，但需将其中结构 A 换成结构 B：换出 A 工程量 0.3 m³/m²、单价 400 元/m³；换入 B 工程量 0.35 m³/m²、单价 500 元/m³。求修正后概算指标。
解：先减换出、再加换入 修正指标 = 1200 − 0.3×400 + 0.35×500 = 1200 − 120 + 175 = 1255 元/m²
答：修正后概算指标 1255 元/m²。

13人材机消耗定额与工料单价

定额是计价的"标尺"：先定人工、材料、机械台班的消耗量，再乘各自单价得人材机费。

人工/机械定额（互为倒数）
时间定额 × 产量定额 = 1
时间定额=完成单位产品所需工日(台班)；产量定额=单位工日(台班)产量；综合时间定额先加、后取倒数
人工与机械台班定额同理
材料消耗定额
消耗量 = 净用量 × (1 + 损耗率)
损耗率 = 损耗量 / 净用量 ×100%（基数是净用量！）；反求 净用量 = 消耗量/(1+损耗率)
材料消耗定额=净用量+损耗量
材料单价（连乘·顺序不能错）
材料单价 = (原价 + 运杂费) × (1+运输损耗率) × (1+采购保管费率)
四块：材料原价、运杂费、运输损耗费、采购及保管费
采购保管费在最外层，先算运损再算保管
机械台班单价（折旧费）
台班折旧费 = 机械预算价格 × (1−残值率) / 耐用总台班
台班单价七项：折旧费+检修费+维护费+安拆及场外运费+人工费+燃料动力费+其他费；耐用总台班=折旧年限×年工作台班
折旧费是台班单价最大头
人材机费用汇总
人材机费 = Σ(消耗量 × 相应单价)
人工费=Σ用工×日工资单价；材料费=Σ消耗量×材料单价；机具费=Σ台班×台班单价
分部分项工料单价的主体
⚠ ①时间定额与产量定额互为倒数，综合定额只能"先加时间定额、后取倒数"；②材料损耗率以净用量为基数；③材料单价是连乘，采购保管费率在最外层，顺序颠倒即错。
经典例题 13-A材料单价
某材料原价 500 元/t，运杂费 30 元/t，运输损耗率 1%，采购保管费率 2%。求材料单价。
解： 材料单价 = (500 + 30)×(1+1%)×(1+2%) = 530×1.01×1.02 = 530×1.0302 = 546.01 元/t
答：材料单价 546.01 元/t（先乘运损、再乘采购保管，顺序不可换）。
经典例题 13-B台班折旧费
某施工机械预算价格 90 万元，残值率 4%，耐用总台班 3000 台班。求台班折旧费。
解： 台班折旧费 = 900 000×(1−4%)/3000 = 900 000×0.96/3000 = 864 000/3000 = 288 元/台班
答：台班折旧费 288 元/台班。

14工程量清单综合单价与造价合成

清单计价的核心是"综合单价"，再逐层合成分部分项费、措施费、其他项目费、规费、税金。

综合单价
= 人工费+材料费+施工机具使用费+企业管理费+利润(+风险)
注意：综合单价不含规费和税金
按每个清单项目计
分部分项工程费
= Σ(清单工程量 × 综合单价)
工程量按清单规则计算
造价主体部分
单位工程造价（税前→含税）
造价 = 分部分项费 + 措施项目费 + 其他项目费 + 规费 + 税金
税金 = (税前造价)×增值税率
逐层汇总
⚠ 综合单价 = 五项（人材机管利）＋风险，不含规费、税金（"综合"是综合了管理费和利润，不是综合了规费税金）。规费、税金在最后统一计取。
经典例题 14-A造价合成
某单位工程：分部分项费 800 万、措施项目费 60 万、其他项目费 40 万、规费 30 万，增值税率 9%。求含税造价。
解： 税前造价 = 800+60+40+30 = 930 万元 税金 = 930×9% = 83.7 万元 含税造价 = 930 + 83.7 = 1013.7 万元
答：含税造价 1013.7 万元。

15工程计量与支付

合同价款计算高频区：预付款起扣与进度款、质量保证金，以及物价波动、工程量偏差与清单缺陷引起的价款调整。

预付款、进度款与质量保证金

预付款起扣点
T = P − M / N
P承包合同总价 · M预付款限额 · N主要材料及构件所占比重
累计完成工程价款达 T 后开始起扣预付款
每次抵扣（起扣后）
本期抵扣额 = 本期完成工程价款 × N
按主材比重逐期扣回，至预付款扣完
保证竣工前预付款全部收回
进度款与质量保证金
质保金 = 结算总价 × 比例（一般≤3%）
进度款 = 已完合格工程价款 × 支付比例 − 应扣回（预付款抵扣＋质保金预留）；质保金一般不超过结算价 3%
缺陷责任期满且无缺陷返还质保金

物价波动引起的价款调整（两种方法）

法一 · 价格指数调整法（调值公式法）
结算价 = P₀(a₀ + a₁·F₁ₜ/F₁₀ + a₂·F₂ₜ/F₂₀ + …)
P₀基准期完成价款 · a₀定值权重（不调，如10%）· aₙ各可调因子变值权重 · Fₙₜ/Fₙ₀=现行/基准价格指数；a₀+Σaₙ=1
价格指数可查、工期长的大合同
法二 · 造价信息调整法（价格信息调差法）
调整额 = Σ 用量 × (现行发布价 − 基准价中超风险幅度部分)
按造价管理机构发布的价格信息调整；材料价格涨/跌超过约定风险幅度（常取±5%）的部分才调，幅度内自担
主要材料、设备价格调整（无价格指数时）
⚠ 造价信息法"基准"取法易错：投标单价低于基准单价时，涨价以基准单价为基础、跌价以投标单价为基础算超幅部分；只调超过风险幅度的部分，幅度内价差由承包人承担。价格指数法则按权重×指数比计算，与风险幅度无关，两法不可混用。

工程量偏差与清单缺陷引起的综合单价调整

工程量偏差调整原则
|实际工程量 − 清单量| / 清单量 > 15% → 调综合单价
工程量增加>15%：增加部分单价应调低；工程量减少>15%：剩余部分单价应调高（量增价降、量减价升）
清单缺项/工程量偏差导致量变时
综合单价调整（偏差>15% 的托底 / 封顶）
P₀偏低 → P₁ = P₂(1−L)(1−15%)　｜　P₀偏高 → P₁ = P₂(1+15%)
P₀承包人清单填报综合单价 · P₂最高投标限价(招标控制价)相应综合单价 · P₁调整后单价 · L承包人报价浮动率
当 P₀ 与 P₂ 偏差超 15% 时把单价约束回合理带
💡 综合单价偏差调整三情形：① 当 P₀ < P₂(1−L)(1−15%)：P₁ 上调至 P₂(1−L)(1−15%)（托底）；② 当 P₀ > P₂(1+15%)：P₁ 下调至 P₂(1+15%)（封顶）；③ 当 P₀ 落在 [P₂(1−L)(1−15%)，P₂(1+15%)] 区间内：可不调整。实质是把偏离过大的报价拉回招标控制价附近的合理区间。
经典例题 15-A起扣点
某工程合同总价 1000 万元，预付款限额 200 万元，主要材料及构件所占比重 60%。求预付款起扣点。
解： T = P − M/N = 1000 − 200/0.6 = 1000 − 333.33 = 666.67 万元
答：当累计完成工程价款达 666.67 万元时开始起扣预付款；之后每期按完成价款×60% 抵扣。
经典例题 15-B调值公式
某月完成工程款基期价 500 万元，调值：固定权重 a₀=0.15，人工 a₁=0.35（指数由 100 涨至 110），材料 a₂=0.50（指数由 100 涨至 120）。求调整后结算款。
解： P = 500×(0.15 + 0.35×110/100 + 0.50×120/100) = 500×(0.15 + 0.385 + 0.600) = 500×1.135 = 567.5 万元
答：调整后结算款 567.5 万元（较基期增加 67.5 万元）。
经典例题 15-C造价信息法
某工程一批钢筋用量 200 吨，投标报价采用的基准单价 4000 元/吨（等于造价信息基准价），施工期造价信息发布价涨至 4600 元/吨。合同约定材料价格风险幅度 ±5%，超过部分调整。求价差调整额。
解：涨价以基准单价为基础，风险幅度上限 = 4000×(1+5%) = 4200 元/吨 现行价 4600 > 4200，超风险幅度部分 = 4600 − 4200 = 400 元/吨 调整额 = 400 × 200 = 80 000 元 = 8 万元（发包人补偿承包人）
答：发包人应补价差 8 万元；5% 幅度以内的 200 元/吨价差由承包人自担。
经典例题 15-D工程量偏差·单价调整
某清单项目最高投标限价综合单价 P₂=100 元，承包人填报 P₀=140 元，承包人报价浮动率 L=5%。施工中该项工程量偏差超过 15%，需调整综合单价。求调整后综合单价 P₁。
解：先算合理区间上、下限 上限 = P₂(1+15%) = 100×1.15 = 115 元；下限 = P₂(1−L)(1−15%) = 100×0.95×0.85 = 80.75 元 P₀=140 > 115（超上限）→ 按封顶调整：P₁ = 115 元
答：调整后综合单价 P₁ = 115 元（因 P₀ 高于 P₂(1+15%)，按上限封顶）。

16国际工程投标报价

在总报价确定后，用报价技巧调整各子项单价，在不抬高总价的前提下改善现金流与索赔空间。

不平衡报价法（原则）
总价不变，调整各分项单价
早结算/预计工程量增加项 → 单价报高；后期/预计工程量减少项 → 单价报低
改善现金流、争取索赔与结算收益
投标报价构成
报价 = 直接费 + 间接费 + 暂列/暂估 + 分包 + 风险费 + 利润 + 税金
国际工程还含现场管理费、总部管理费、保函/保险费等
先算成本、再定加价（Mark-up）
⚠ 不平衡报价的前提是总报价不变、不影响中标；调整幅度过大反而暴露意图或被判废标。工程量清单中预计会增加的项目报高价、会减少的报低价——判断方向不要反。
